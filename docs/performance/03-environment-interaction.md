# 人物表演与环境交互理论：对象、接触、支撑与后果

研究与来源访问日期：2026-09-28。[调研计划](research-plans/02-environment-research-plan.md)先确定了取证范围和问题。本文供后续创建「表演 SKILL」时使用，研究成年真人风格短视频中的人物与地面、门、家具、容器、小道具以及另一人物共享物体的关系。镜头可由近景延伸到全身；正文给的是**表演编排与验收框架**，不是人体运动数据库、物理模拟器或视频生成模型的能力声明。与本系列的[面部表演与时序理论](01-facial-performance.md)及[肢体运动理论](02-body-performance.md)合用：面部篇负责局部可见动作，肢体篇负责人体自身的运动，本篇负责人与物／场景之间的约束和后果。本文没有生成样本、驱动片测试或观众盲评。

## 先分清证据与任务

| 层次／等级 | 本文怎样使用 | 边界 |
| --- | --- | --- |
| **A：原始研究发现** | 指向原论文或原著，只报告其实际对象、任务和观测结果 | 不把单一实验的比例、时长、动作顺序变成所有角色的规则 |
| **B：制片推导** | 将证据转为对象卡、接触阶段、镜头可见性与连续性检查 | 是便于制作与复核的表示法；不是论文直接验证过的 AI 视频方法 |
| **C：待实测假设** | 给未来 SKILL 可测试的描述方式、提示词和评价方案 | 未证明某个生成工具可执行指定接触时点、力量、手指位置或物理状态 |

本篇的一般原则是：**先定义场景中有什么、角色要改变什么，再描述朝向、接近、接触、操纵与释放，并记录交互后的环境状态。** 人类行为研究可以帮助选择可观察的阶段，但不能根据影像反推角色的真实心理、物体准确重量、接触力或材料摩擦系数。观众能否看清这些阶段还取决于景别、遮挡和剪辑；模型是否能生成它们必须单独验证。

## 一手证据能支持哪些判断

### 1. 可行动性是角色与环境的关系

**A。** Gibson 在《生态视觉知觉》的“可供性”章节把环境提供的行动机会放在动物与环境的关系中讨论；这里借用的只是“同一物体对不同身体和任务可能提供不同动作”的分析视角。[Gibson 原著章节](https://monoskop.org/images/c/c6/Gibson_James_J_1977_1979_The_Theory_of_Affordances.pdf) Warren 的三个楼梯实验研究阶高与受试者腿长之间的关系，样本为 54 名男性大学生；Warren 与 Whang 又用不同宽度门洞记录行走者是否旋肩通过，并比较可通行判断。它们说明**身体尺度与空间尺度的关系**会影响行动选择，但不能把论文的门洞阈值写成不同体型、携物、轮椅或表演情境的统一阈值。[Warren 1984 原论文摘要与 DOI](https://doi.org/10.1037/0096-1523.10.5.683)、[Warren 与 Whang 1987 原论文记录](https://pubmed.ncbi.nlm.nih.gov/2958586/)

**B。** 写“穿过门”时，应先写门是否开启、通道是否被占、人物是否携物、目标是否在门另一侧；如果空间关系要求侧身、让路或移开障碍，再写这类可见调整。可供性不等同于角色意图：椅子可供坐下，角色也可能选择绕过它。

### 2. 视线服务当前操作，也会预备下一步

**A。** Land、Mennie 与 Rusted 在日常泡茶任务中同步记录眼动与行动，观察到注视多指向正在操纵的物体，任务无关注视很少。Hayhoe 等在制作三明治的自然任务中跟踪眼手运动，发现许多视觉信息在需要时取得，同时仍有跨数次注视维持的场景空间信息和数秒尺度的计划；这不支持“视线总严格先于手”或“只看当前手中的物体”。[Land 等 1999 原论文 PDF](https://www.cis.rit.edu/pelz/scanpaths/papers/teamaking-land-mennie-rusted-1999.pdf)、[Hayhoe 等 2003 原论文 PDF](https://www.cis.rit.edu/people/faculty/pelz/publications/Hayhoe_shrivastava_mruzck_pelz_j_vision_2003.pdf)

**B。** 环境交互卡应给视线一个**具体目标**：杯柄、门把、门缝、接物者的手、落座处，而不是只写“看向前方”。可以让看、伸手、转身重叠；把每次转移的原因写在事件线上。镜头若看不到眼睛，就用头部朝向、手的目标、物体反应和声音维持信息，而不是声称观众一定看到了注视。

### 3. 抓握有运输、手形准备、接触与负载过程

**A。** Jeannerod 用影片分析 7 位成年受试者的抓取，发现手向目标的运输与手指形成抓握在时间上重叠，手指会在接触前调整；该实验的具体速度比例只属于所测抓取，不应复制到其他物件。[Jeannerod 1984 原论文记录](https://pubmed.ncbi.nlm.nih.gov/15151851/) Johansson 与 Westling 用传感器记录小物体的指尖捏取、提起、移动和放回，抓握力与负载力会协同变化，并随物体表面摩擦及滑动反馈调整；他们记录的是**不可直接从普通视频读取的力和触觉信号**。[Johansson 与 Westling 1984 原论文记录](https://pubmed.ncbi.nlm.nih.gov/6499981/)

**B。** 可见表演不需要假装展示精确牛顿数。需能看到一个可信的关系：手在目标物体附近形成合适接触，物体从支撑面离开的时点与持握一致；若物件滑动，角色有可解释的调整；放下后物件由桌面等新支撑物承接。不要让手指穿过物体、持握点沿表面无因漂移，或在手仍远离物体时让物体跟随。

### 4. 坐、站和移动是支撑关系的转换

**A。** Schenkman 等用全身运动分析把从椅子起身描述为连续阶段，包含前倾以产生动量、臀部离座、伸展及稳定；其研究对象和实验条件不提供所有角色都必须用同一角度、时长或手部支撑的标准。[Schenkman 等 1990 原论文记录](https://pubmed.ncbi.nlm.nih.gov/2217543/) Warren 与 Whang 的门洞研究亦显示路径和躯干朝向会随通道相对于身体的尺寸改变。[原论文记录](https://pubmed.ncbi.nlm.nih.gov/2958586/)

**B。** 对“起身”至少记录**椅面是否承重 → 双脚何时承重 → 身体何时稳定**；对“坐下”反向记录何时与椅面接触、椅子是否保持位置。扶桌、拄杖、扶手等为角色具体条件，不能默认每个人必须使用。空间受阻时，写清是角色侧身、移开物体、换路径还是行动失败。

### 5. 递物是双人共同改变物体持有关系

**A。** 一项 22 人参与的双人递物实验同时测量递交者与接收者的抓握力；在该研究的固定器具和坐姿条件下，两人的受力变化在交接阶段协调，遮挡视觉、戴手套或改变接收者伸手速度都会影响交接的时序或力变化。[Döhring 等原始实验全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7759571/) 另一项 20 人参与的实验改变搭档和距离，并比较有无在线视觉反馈，显示交接地点会随搭档条件调整；这些结果不代表所有递物都要双眼对视，也不提供固定的交接距离。[Kato 等原始实验全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6588208/) Kutz 等另外研发同步记录双人手臂运动与抓握力的测量系统，用伸取、运输、转移、结束等阶段处理交接；这为**测量阶段边界与力**提供方法，普通成片只能检验可见接触和持有者变化，不能证实握力曲线。[Kutz 等 2023 原始方法论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10747505/)

**B。** 交接卡应明确“谁先持有、谁先到达交接点、是否有双方同时接触、谁先放开、谁带走”。直接手递手可安排短暂的双方共同接触；放在桌上由另一人再拿、抛掷或剪辑省略动作时，交接机制不同，应明确写出物体的中间支撑与状态。视线可落在物体、交接点或对方，依据角色任务选择。

### 6. 观众理解的是有层次的行动事件

**A。** Zacks、Tversky 与 Iyer 让观察者分割日常活动录像，粗粒度和细粒度的事件边界呈层级对应，且描述任务会影响这种对应。该研究检验的是**观察者的事件分割**，没有直接测试 AI 视频中“杯子瞬移”是否会被注意，也不意味着所有动作都要分成相同数量的步骤。[Zacks 等 2001 原论文 PDF](https://www.tc.columbia.edu/faculty/bt2158/faculty-profile/files/grememberingandcommunicatingstructureinevents.pdf)

**B。** 因此可同时写两层：上层“角色把水杯递给同伴”，下层“定位杯柄、抓取、离桌、移至交接点、共同接触、松手”。下层可以在镜头中被剪掉或被遮挡，但**物体前后状态**仍要自洽；不能因为没有拍到放下动作，就让下一镜物体无说明地换位置。

## 将证据转为可执行的交互表示

### 统一表演卡接口

本表与面部、肢体两篇共用字段。字段是 **B：制片表示**，不是某论文或生成工具已认可的数据格式。每项可写文字、相对时序或区间，不需要伪造精确秒数。

| 字段 | 环境篇要写什么 | 例：起身取门边的杯子 |
| --- | --- | --- |
| 外部事件 | 角色看到／听到的变化 | 门铃响；杯子仍在门边桌上 |
| 角色任务 | 角色要完成的可观察目标 | 起身、拿杯、走向门；剧作意图另记 |
| 身体基线 | 当前姿势与运动状态 | 坐在椅上，双脚落地，右手空闲 |
| 空间目标 | 人、物、落点及路径关系 | 杯柄在桌面右侧；门在画面左后方 |
| 动作阶段 | 可先后或重叠的变化 | 前倾、离座、定位杯柄、伸手、提杯、转身 |
| 视线／声轨 | 看向哪里，声音何时发生 | 门铃后看门，再看杯柄；脚步声随移动 |
| 接触／支撑 | 谁接触谁，谁在承重 | 椅面／双脚 → 双脚；桌面／右手 → 右手持杯 |
| 环境前后状态 | 物体状态及变更 | 杯子从桌面移走；椅子位置不变；门仍关着 |
| 镜头可见性 | 哪个证据出现在画内 | 中景见离座和抓杯；特写只见杯柄接触 |
| 结束条件 | 动作停止、残留或进入下一事件 | 右手持杯站稳，准备去开门 |
| 证据等级 | 每个结论的来源性质 | 阶段受研究启发为 B；指定时点为 C |

**接口约定。** 面部篇的 `onset / apex / offset` 记录局部可见动作的生命周期；本篇的“首次接触、支撑转移、物体释放”记录**关系状态改变**，两者可以错峰。肢体篇确定关节和全身运动的内部协调；本篇只规定它必须与对象位置、接触和支撑相容。声轨若有对白，沿用面部篇的音频对齐；环境音只在可见事件和声音之间做同步核对。

### 对象卡、接触图与状态账本

**对象卡（B）。** 每个与行动相关的对象至少记录：`id`、类型与外观、初始位置和朝向、可操作部位、可移动／铰接／固定、初始状态、与角色的相对位置、画内可见范围。物体材质或重量只有剧本和道具设定明确时才填；不能从画面风格猜数值。

**接触与支撑图（B）。** 用“角色部位 ↔ 对象部位”记接触边，用“谁承重谁”记支撑边。例如 `右手 ↔ 杯柄`、`杯底 ↔ 桌面`、`左脚／右脚 ↔ 地面`。每条边的状态写成 `未接触 / 接近 / 接触 / 承重或施力 / 释放`。在模糊遮挡处标 `不可见`，不要强行判为接触。支撑边可以重叠：提杯前手已碰杯而杯底仍在桌面；递物时双方可同时持物。

**环境状态账本（B）。** 事件逐条记录 `对象 id | 前状态 | 触发动作 | 可见或可听反馈 | 后状态 | 下一镜继承状态`。例如 `door_1 | 关、锁舌未知 | 角色按把手并推门 | 门扇旋开 | 开 | 下一镜仍开`。声音可说明画外事件，却不能自动证明画内对象已发生特定移动。液位、碎片、衣物、家具和影子只在本镜或后续镜头相关时追踪。

### 交互事件的相对时间线

把目标写为可检验的关系变化，而不是固定的动作清单。通用候选链为 `发现／确认目标 → 调整位置与朝向 → 接近目标 → 建立接触 → 施力或承重转移 → 观察反馈 → 释放或维持 → 环境后状态`。泡茶和抓握研究支持视觉与操纵阶段会协调；各阶段可重叠、失败后可回退，未使用的阶段可省略。[Land 等原论文](https://www.cis.rit.edu/pelz/scanpaths/papers/teamaking-land-mennie-rusted-1999.pdf)、[Jeannerod 原论文](https://pubmed.ncbi.nlm.nih.gov/15151851/)

相对关系用 `before`、`after`、`overlap`、`until` 标记。例如 `手触杯柄 before 杯底离桌`；`接收者接触杯身 overlap 递交者仍持杯`；`门扇开启 after 推门施力`。剪辑可以省略中段，但下一镜的对象位置与持有者应从上一镜的结束状态继承。**C：**文字提示能否让特定模型忠实执行这组先后关系，目前未实测。

## 五个情境：从模糊指令到可验收过程

以下全部是 **B：制片推导**；“当……之后”是相对事件条件，不是人体通用秒数。若转成具体生成提示，均为 **C：待实测假设**。

| 情境 | 前状态与角色任务 | 关键接触／支撑与可见过程 | 后状态、镜头证据与易错处 |
| --- | --- | --- | --- |
| **取杯并放下** | 杯 `cup_1` 在桌上，角色要把它移到书旁 | 视线定位可握部位；手形在接近中变化；手与杯接触后杯底才离桌；移动中杯随手保持相对稳定；放回时杯底先接触书旁桌面，手再释放 | 杯在新落点保持不动。中景应看见至少一次离桌和落桌；近景若遮住手，要靠杯子与桌面的接触变化交代。查手杯漂移、杯底悬空和液位无因变化。 |
| **开门进入** | 门 `door_1` 关，角色在门外，目标在门内 | 接近门把／门缘；触碰可操作部位；门扇沿铰链方向变化；人物调整路径或身体朝向通过门洞；手可在通过前或通过中放开，按具体走位选择 | 角色在门内，门的开闭状态继续存在。镜头要交代门铰链、门扇或开口其中一项。查门扇穿过人物、角色在开口出现前穿门、下一镜无因复位。 |
| **坐下后起身** | 角色坐在 `chair_1` 上，双脚触地；任务是站起走开 | 起身时身体前移并从椅面离开，支撑从椅面与脚共同承重转向双脚；迈步可与起身末段衔接，但支撑关系须连续。若以扶手借力，记录手扶手接触和释放 | 椅子原位，角色站立并离开。全身或中景验证椅面与臀部脱离、脚地接触；只拍脸部近景不能证明支撑转移。查臀部穿椅或站起后椅子跟随。 |
| **双人递交物体** | 甲持 `book_1`，乙双手空闲，目标是乙接到书 | 甲把书递到乙可达区域；乙手接触并建立持握；短时双方同时接触；甲松手后乙带走。眼神各有明确目标，可以先看书、后看对方 | 持有者由甲变乙。至少一个镜头见交接点及双方手；若剪切省略双人同时接触，前后镜的持有人和书的位置仍连贯。查甲过早松手导致书悬空、书在手间瞬移。 |
| **受阻后修正** | 角色想开抽屉 `drawer_1`，但抽屉前有椅子 | 角色定位拉手、尝试拉动；若抽屉未动，给出可见阻力或碰撞反馈；角色停止、看向障碍，移椅或改从侧面开，之后再尝试 | 抽屉保持关着直到障碍被处理，椅子新位置保留。镜头要让观众看到障碍或动作失败的反馈；否则“改动作”可能没有可读原因。查抽屉无因穿椅、第一次已打开却又重试。 |

表中“前倾”“视线定位”“短时同时接触”来自不同任务的观察与制片整合，**不能**要求每位演员机械复刻。抓握的时序参考[Jeannerod 的七人抓取实验](https://pubmed.ncbi.nlm.nih.gov/15151851/)，坐站支撑参考[Schenkman 等起身研究](https://pubmed.ncbi.nlm.nih.gov/2217543/)，递物共同接触参考[Döhring 等测力实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC7759571/)；抽屉受阻是用于检查因果链的原创示例，没有上述实验直接验证。

## 失真分类与验收

| 失真 | 逐帧检查 | 整段检查 |
| --- | --- | --- |
| 目标漂移 | 手的接触点、门把／杯柄等目标部位是否在相邻帧稳定 | 观众能否看出角色针对哪个对象行动 |
| 接触缺口或穿透 | 首次接触、持物、释放三处有无手与物分离或相互穿过 | 物体是否在无人持有且无支撑时悬空跟随 |
| 支撑矛盾 | 离座、落座、离桌、落桌时哪条承重边成立 | 从坐到站、从桌上到手中是否有可解释的转移 |
| 物体状态跳变 | 门角度、杯液位、衣物形态、碎片位置是否突变 | 跨镜头的对象 `id`、位置、开闭和持有人是否继承 |
| 视线与行动脱节 | 看向目标与伸手／接触有无可理解的关系 | 是否存在角色从未发现障碍却准确避让的无因动作 |
| 反馈缺失 | 推门、拉抽屉、碰撞或滑脱后物体是否有相应变化 | 失败后的修正是否由可见／可听反馈触发 |
| 镜头证据不足 | 关键交接、支撑点是否被画面裁切或遮挡 | 仅凭全段能否判断任务是否完成，而非只凭剧本说明 |

**验收顺序（B）。** 先按对象账本核对每次状态转移，再看接触与支撑的关键帧，最后在正常速度下看角色任务是否清楚。画面遮挡的阶段标为“无法判断”，不能当成通过；需要时改景别或增加能显示关键关系的镜头。对有意使用跳切或画外动作的作品，可让声音、前后状态或下一镜补足信息，但要写明这种省略是叙事安排。

## 可证伪的下一轮验证

以下均是 **C：未实测设计**。先选一个确定版本的视频工具，再记录其输入方式和限制；文字、参考帧、驱动视频或可编辑关键帧可能支持不同粒度。每个条件用相同人物、对象、起止帧、时长和随机种子（若可设置）；至少比较“仅写结果”与“给对象、接触、支撑及后状态”的提示。不能因单次成功就声称 SKILL 有效。

1. **接触顺序。** 任务：取杯、放杯、递书。盲评者按事件点标记 `手接触`、`离支撑面`、`新支撑建立`、`原持有者释放`。若结构化描述不能降低顺序错误，或改进只出现在某一个道具上，该规则的有效性受限。
2. **状态持久性。** 任务：开门通过、移椅后开抽屉。逐镜核对 `id`、位置、朝向、开闭与持有者；统计对象突变和无因复位。若模型输出把物件替换或复位，即使动作看似自然，也判交互不成立。
3. **支撑转移。** 任务：坐到站、拾取桌上物体。要求中景或全身镜，逐帧标注椅面、脚、桌面、手的可见接触；遮挡比例单列，不把不可观察样本算作正确。
4. **可读性与自然度分开。** 让盲评者分别回答“谁对哪个物体做了什么、物体最后在哪里”和“整体动作是否自然”；另记失真类别。若任务判断正确但接触仍穿模，不能把“可读”评分代替物理连续性。
5. **外推边界。** 换手、换体型、携带负载、改变场景狭窄度和镜头角度；先在同一任务逐项改变一个条件。若只在正面空场景可复现，则将其写成该场景适配，而不是通用表演理论。

目前未知：目标视频模型对手指与物体接触、跨镜头物体身份、门铰链、承重、液体和声音同步的可控精度；不同文化、年龄、行动能力及专业表演训练下的时序差异；在极短片段和高遮挡镜头中哪些信息最有助于观众理解。这些未知需要针对工具和受众另测。
