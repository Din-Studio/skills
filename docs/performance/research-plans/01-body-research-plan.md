# 表演时肢体运动理论：调研计划

计划日期：2026-09-28。目标是为未来「表演 SKILL」建立可追溯的肢体表演理论与制片约束；本文件只规定下一阶段的研究问题和取证方法，**不把候选理论当作已核实结论**。目标应用是角色表演的创作与 AI 视频生成复核，优先覆盖成年人物、短镜头、从近景到全身镜头。最终文档拟放在 `docs/performance/02-body-performance.md`。

## 与现有表情研究的接口

[面部时序研究](../01-facial-performance.md)已经把表演写成「外部事件 → 角色任务 → 可见反应 → 结束条件」，区分文献支持、设计规则和设计假设，并用相对先后关系组织面部、眼神、头姿、声轨与镜头。肢体文档沿用这个证据和时间框架，但不把面部 AU 映射扩展成全身的固定情绪动作。头、躯干和四肢可能共享一个动作目的，也可能出现局部延迟、补偿或冲突；这些关系需要依据具体任务和资料研究。

本专题研究人体自身的运动组织与其可见表演含义。物件、地形、门、椅、其他人物等**环境接触和交互事件**由相邻的「人物表演与环境交互理论」专题主述；本篇仍须记录支撑、接触、遮挡和空间目标，因为它们直接约束肢体动作。两个专题的共同接口为：事件、动作目标、身体状态、空间目标、接触状态、相对时序、可观察验收点和不确定性。

## 研究方向与待回答问题

| 优先级 | 方向 | 必须回答的关键问题 | 对未来 SKILL 的可用产物 |
| --- | --- | --- | --- |
| P0 | 表演的动作单位与层级 | 如何把「走过去」「想触碰却停住」等意图拆成准备、发起、执行、调整、结束？全身、躯干、头和手的动作如何分层，而不误设全身同步？ | 事件到动作的分解表；动作生命周期字段；相对时序词表 |
| P0 | 姿态、支撑与重心 | 站、坐、起身、转身、迈步时，支撑面与重心转移如何影响可见姿态？哪些“好看”的姿势在运动中缺乏平衡或连续性？ | 基线姿态、支撑脚／面、重心趋势和稳定状态的标注法；平衡检查项 |
| P0 | 起动、停止与动作连续性 | 到达目标之前是否有可见的准备、预期和修正？速度、加速度、运动弧线、惯性等如何被可靠观察；何时只是风格选择？ | 起始／转折／完成／残余的标注法；突跳、脚滑、关节漂移检查项 |
| P0 | 手势与言语／注意力协同 | 指示、描绘、节拍、持物、安抚等手势与说话、注视和身体朝向有何可验证的关系？是否存在不能泛化的语言、文化及任务差异？ | 手势功能与空间目标字段；声轨与手势的相对时序约束；互相冲突的动作提示识别 |
| P0 | 观察者如何读懂身体动作 | 姿态、运动方向、速度和场景上下文如何影响观众对行动、意图或情绪的判断？在何种实验任务中动态线索优于静帧？ | “可见动作”与“观众解读”分层的写法；整段与关键帧分开的验收设计 |
| P1 | 步态、转身与空间路径 | 走、停、回头、绕行、接近和退后有哪些可观察的相位？角色速度、步幅、朝向、注视和镜头如何相互影响？ | 路径、朝向、步态相位、目标点和转身节点的制片卡字段 |
| P1 | 身体的对话与社交编排 | 倾听、轮次转换、靠近／后退、呼应和抑制动作是否有可靠证据？如何避免把个人空间或礼仪写成跨文化常量？ | 对话中动作与声轨／目光／伙伴动作的事件关系；文化边界提示 |
| P1 | 表演风格与角色差异 | 演员训练中的动作质量、力度、节奏、空间取向如何作为创作词汇？哪些来自教学体系而非受控实验？年龄、体能、角色习惯和镜头风格如何改变动作？ | 可选择的风格维度及其可观察定义；不把风格词当生理定律的提示模板 |
| P1 | 生成与动画的约束 | 文本提示、姿态参考、动作驱动片、骨架曲线各能承载哪些动作要求？二维成片中怎样区分身体动作、人物整体位移和相机运动？ | 输入能力与验收能力分开的适配表；无法保证的控制项标注 |
| P2 | 多人物同步与复杂动作 | 搀扶、拥抱、追逐等动作中的相位关系如何表示？如何限制本专题对双人和物理接触的论断？ | 跨角色动作依赖的简化接口；明确转交环境交互篇的范围 |

## 优先查找的原始资料

以下均是**候选检索入口**，下一阶段须核对原文、版本、方法、样本、任务与结论，不能仅凭书名或二手摘要下结论。

1. **运动与知觉基础**：Johansson 的生物运动点光源实验原文；Gibson 关于知觉与环境供给性的原著；Newell 关于协调与约束的原论文；Bernstein 关于运动协调的原著；Flash 与 Hogan 关于有目标手臂运动轨迹的原论文。重点区分“实验参与者在特定任务中的轨迹规律”与“所有角色动作应采用的插值函数”。
2. **动作准备、抓取及姿势转换**：以原论文检索预备姿势调整（anticipatory postural adjustments）、到达／抓握协同、坐站转换、步行起动和转身研究。优先实验室原始数据、系统综述的原始引用链及可重复的方法定义；记录年龄、负重、速度、地面和测量条件。
3. **手势与交流**：Kendon、McNeill 和 Goldin-Meadow 的原著及可获得的手势—语音同步实证论文；检索面对面会话的手势、目光、身体取向研究。分别处理“手势分类框架”“共现证据”和“具体相位”的强弱，不把所有说话动作变成必须打手势。
4. **身体动作的感知**：de Gelder、Atkinson 等关于身体表达和点光源动作识别的原始实验；同时寻找与其结果相反或限定动态优势的研究。逐项记录刺激是否保留面部、场景、声音、移动路径，以及被试回答的是动作、情绪还是社会意图。
5. **表演及动画创作体系**：Laban／Bartenieff 原著、Stanislavski 的身体动作方法原著，以及可核实的角色动画原始制作资料。把它们作为**创作／教学框架**评估，不以其权威替代人体运动或观众感知的因果证据。
6. **AI 视频与动画实现**：目标生成工具的官方接口文档及相关原始论文，核对姿态、动作驱动、时间点、相机、接触与身份保持的实际控制粒度。只有完成目标模型样本测试，才能称“已验证能控制”；纯文献调研只给接口与风险边界。

检索优先顺序为论文全文／出版社原文／作者或机构公开稿、官方模型文档、原始书籍。综述用于找论文和梳理分歧，最终关键主张回到原始资料。每个来源登记发表年份、访问日期、研究任务、样本／刺激、测量指标、支持的最窄论断、迁移限制与链接；无法取得全文时标明“仅核对摘要”。

## 调研的取证与冲突处理

- 将结论分为 **文献支持**、**设计规则**、**设计假设**、**目标模型实测** 四类。原论文中的观察规律不能直接升级为 AI 视频控制能力；创作体系的术语不能冒充实验验证。
- 优先记录**动作或任务条件**，避免“交叉双臂＝防御”“慢走＝悲伤”“左手动作＝某种性格”等一一对应的读心式解释。角色内在意图是剧本输入，观众解读是待测结果。
- 区分人体运动学、角色动画中可读的夸张动作、具体镜头剪辑和生成模型伪影。三者可以相互参考，但不能用其中一种的数值阈值统治其余两种。
- 任何精确秒数、关节角、步幅、动作强度都须标明人群与任务的来源；没有目标演员或视频标定时，只提供相对顺序与强度序数，具体数值写作待验证假设。
- 对方向相反的研究保留条件差异：单帧／动态、实验室／自然场景、真实演员／合成身体、独行／交流、不同文化与身体能力。不要用一个“自然度”评分覆盖动作命中、物理连续性和叙事可读性。
- 证据不足的方向给出可证伪的对照实验：同人物、同事件、同镜头，仅改变一个动作轨或相位；分别记录关键帧命中、整段动作连续性、观众意图判断、身份／身体一致性。

## 预期最终文档的结构与交付标准

`docs/performance/02-body-performance.md` 预计采用以下结构，调研后可根据证据调整：

1. 适用范围、证据等级与和面部／环境交互篇的接口。
2. 动作的层级与生命周期：任务、基线、准备、发起、执行、修正、结束及残余；写清与面部 `onset／apex／offset` 的对应和差异。
3. 姿态、支撑、重心、步态与转向的可见约束；把身体内部机制与成片可观察线索分开。
4. 手势、身体朝向、注视和言语的协同；说明任务、情境、角色和文化边界。
5. 一张可用于未来 SKILL 的「肢体表演卡」：输入事实、空间目标、动作事件链、身体分轨、相对时序、接触依赖、镜头、冲突与验收点；附带具体情境示例，所有未实测参数显式标为假设。
6. 失真分类：脚滑、支撑错位、关节断裂、根运动／相机运动混淆、手势和声轨错位、目标失靶、动作无准备、全身机械同步、静帧正确但整段不通等。每项都有可观察检查法。
7. 可证伪的验证方案、未解问题和逐条来源表。

完成标准：每个核心理论点至少有可查的原始来源及其任务边界；每条供 SKILL 使用的规则能追溯到证据或明确标为制片推导；具体时间／强度不伪装为通用常数；对生成模型能力不作未经实测的保证；文档能独立指导创作者写出并复核一段身体表演，而不依赖 `.prp/` 私有研究目录。
