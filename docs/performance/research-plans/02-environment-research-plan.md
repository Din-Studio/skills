# 人物表演与环境交互理论：调研计划

计划日期：2026-09-28。目标产物：`docs/performance/03-environment-interaction.md`，供后续创建「表演 SKILL」引用。此文是**检索与写作计划**，其中列出的理论和文献均为待核验线索，不预先视为已获证据。

## 研究任务和边界

回答一个制片问题：当角色要与房间、地面、家具、门、容器、工具或他人共享的物体发生关系时，怎样把“触碰／拿起／推开／避让”等笼统指令写成有起因、可见过程、接触条件和后果的表演描述。侧重成年真人风格短视频与角色动画，兼顾单人和双人、近景至全身景别；不同体型、行动能力、文化和场景会改变具体实现，不能共用绝对动作幅度或秒数。

本工作流研究**角色与环境之间的关系**。身体内部的运动机制、步态、手势韵律等由肢体运动理论文档主讲；面部局部动作及情绪时间线由现有 [时序表演研究](../01-facial-performance.md) 主讲。本文只在环境交互需要时引用身体轨、视线轨和面部轨，并记录跨文档接口，避免分别写出冲突的固定规则。

研究将严格区分三类陈述：**原始研究观察**（注明任务、样本和条件）、**跨领域制片推导**（说明为何有助于可读的交互）、**待实测生成假设**（例如文字提示词能否控制接触时点）。不会把心理意图、接触力、物体重量或材料触感直接从一帧可见画面反推出来，也不会把动画原则说成普遍的人体运动定律。

## 检索和证据处理

1. **先找一手来源。** 优先原论文、原书中可核对的章节、作者／机构公开全文、官方技术文档。搜索词覆盖 `affordances body scale reachability`、`visual guidance natural object manipulation`、`prehension transport grip aperture`、`postural adjustment sit-to-stand load`、`object handover joint action gaze`、`event segmentation object interaction`、`film blocking prop continuity`。如原著受访问限制，记录可获得的摘要和限制，不用二手转述冒充已读全文。
2. **为每条来源做核验记录。** 记录书目信息、链接、访问日期、研究对象和人数（如适用）、任务／刺激、测得的现象、作者明说的限制、能支持的最窄结论。理论原著、观察性研究、实验、动画实践和生成工具说明分开标注。
3. **对争议保持并列。** 可供性与可达性的定义、人际距离的文化差异、伸手抓握阶段的划分、自然场景对实验室结论的迁移，都可能存在不同模型；不要用一个来源定论所有表演。若证据只覆盖屏幕指向或机器人，则不得直接写成人类真实物体表演规则。
4. **检查可见性和可控性。** 物理约束属于底层合理性，观众能否看到要受景别、遮挡和镜头切换约束；模型能否执行须另有生成实测证据。没有实测时给出可供未来测试的提示词与评估设计，明确标为假设。
5. **保持来源追溯。** 正文关键判断就近标注来源编号和“研究发现／设计推导／待测假设”。文末给原始链接与逐条证据边界，不用悬空的泛泛书单。

## 最终文档的预定结构

1. **范围和三层证据**：人类行为、制片编排、生成控制的边界；与表情及肢体文档的接口。
2. **交互理论证据**：按可供性／可达性、目标定位、接触操纵、支撑与空间、环境反馈、社会交互梳理结果与争议。
3. **可执行分析框架**：场景对象卡、角色任务、目标和接触状态机、身体支撑图、物体状态账本、镜头可见性。
4. **表演卡和跨轨时间线**：展示“事件 → 角色任务 → 身体／视线／接触动作 → 物体反馈 → 结束状态”；以相对先后为主，秒数仅作具体镜头的待测设计。
5. **情境实例**：至少覆盖拿起并放下杯子、开门进入、坐下或起身、递交物体，以及一次交互受阻后的修正。每例标注设计假设，不伪称人体标准时间。
6. **失真分类和验收**：手物穿透／漂移、重力与支撑错误、物体状态不连续、遮挡前后物体瞬移、角色注意目标不一致；给逐帧与整段检查方法及测试边界。
7. **来源清单、未知项与下一轮验证**：逐条列原始来源及其只支持的结论；把工具能力、跨体型和跨文化泛化列为待测。

## 完成判据

- 每个核心制片规则能追到原始证据或明确标为设计推导；关键反例和适用条件写在相邻位置。
- 至少有一个统一的交互表示，同时表达角色、对象、接触、支撑、环境状态、视线、镜头和时间关系；不要求模型具备未验证的参数接口。
- 示例能让人检查交互前后对象的位置／状态及角色是否仍接触它；没有凭空新增或消失的物体、未说明的支撑切换。
- 与表情时序文档的“外部事件—角色任务—可见反应—结束条件”和局部动作生命周期兼容；与肢体文档讨论接缝并避免重复或冲突。
- 在交付时核对链接可访问、书目信息和所引结论；执行仓库要求的 `npm run check`、`npx --yes skills@1.7.0 add . --list`，若本地有 Claude Code，再严格校验两份清单。
