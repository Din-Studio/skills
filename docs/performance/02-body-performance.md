# 肢体表演与运动理论：从动作目标到可见过程

调研与来源核对日期：2026-09-28。[调研计划](research-plans/01-body-research-plan.md)先确定了取证范围和问题。本文为未来「表演 SKILL」准备理论与制片约束，优先服务成年真人风格短视频、单人表演及近景到全身镜头。它不是动作捕捉标准、医学步态规范，也不声称任一 AI 视频模型已能逐帧控制骨架。本文没有生成样本、演员参照或观众盲评。文中的具体时间线都是**待实测设计假设**。

## 范围、证据层次与三篇文档的接口

本文讨论人物**自身**的姿态、重心转移、步行、转身、手臂与手势，以及这些运动如何与视线、声轨和镜头共同构成表演。面部局部动作和 FACS 的使用见[面部表演与时序理论](01-facial-performance.md)；人物与地面、物体、建筑空间及其他人的接触和反馈见[环境交互理论](03-environment-interaction.md)。身体运动必然受到支撑、接触和空间目标限制，因此两篇共享同一事件，而不是各自发明独立时间线。

| 层次 | 本文能给出的内容 | 不可直接推出的内容 |
| --- | --- | --- |
| **研究发现** | 指定样本、任务与刺激下测得的运动或观察者判断 | 所有演员都必须按同一速度、姿态或顺序行动 |
| **制片推导** | 为了让目标和过程可见，如何写动作分轨、支撑状态与复核点 | 该写法已在目标生成模型中被验证 |
| **待实测假设** | 特定镜头的秒数、动作强度、动作间隔、模型提示词 | 人体标准参数或生成系统的可靠控制精度 |

共同接口是一条事件记录：**外部事件、角色任务、身体基线、空间目标、动作阶段、视线／声轨、接触／支撑、环境前后状态、镜头可见性、结束条件、证据等级**。某些项目可以是“未知”或“不适用”；不能为填满表格而捏造内心状态、不可见的受力值或毫米级时间。面部篇的基线、起始、峰值、释放与残余可用于局部身体动作，但步行和起身还有支撑切换等事件，不能强套单峰曲线。

## 研究证据与可迁移边界

### 身体动作被读出，靠的不只是一张姿势图

**研究发现。** Johansson 的点光源行走实验显示，当身体外形大幅削弱，只保留运动中的少数光点，观察者仍能从协调运动中读出人的行动。这说明时间变化可承载身体动作信息，不能从一帧站姿推断整段表演是否成立；但该研究研究的是生物运动知觉，不提供“悲伤步态”之类的情绪配方。[Johansson 原论文 PDF](https://robotics.usc.edu/~maja/teaching/cs584/papers/Johansson_Visual_Perception.pdf)

Atkinson 等让 **10 名演员**遮住脸，表演五种指定情绪及三种夸张程度，并比较全光／点光、动态／峰值静帧的强制分类。该任务中，动态刺激通常比相应静帧更容易分类；夸张程度的帮助随类别变化，悲伤并不符合所有夸张都会提高准确率的说法。它测的是演员按指令演出的**观察者分类**，不是从身体形态读取人物真实情绪，也不能证明短剧观众一定给出同样标签。[Atkinson 等原论文](https://journals.sagepub.com/doi/10.1068/p5096)

**制片推导。** 肢体设计要同时验收“关键姿态是否看得清”和“走到该姿态的过程是否可读”。先写角色要完成的可见行动，再把“紧张”“自信”等词留作希望观众读到的目标；不要一对一映射为缩肩、叉腰或特定步幅。

### 支撑和转移是动作的骨架

**研究发现。** 成年人从静站起步时，脚离地之前常可测到预期姿势调整，但不能据此要求每次起步都有可见的“重心预备动作”。Lu 等让 **157 人**各做五次自发、无提示起步；最终发表的摘要报告四种调整成分中至少一种在 **24% 的试次**缺失，说明准备方式存在差异。压力中心和质心由仪器测得，不能仅凭普通视频逐帧反推出精确轨迹；PMC 作者稿的摘要写作 23%，这里按最终期刊／PubMed 记录采用 24%。[Lu 等最终论文摘要](https://pubmed.ncbi.nlm.nih.gov/28651215/) 起步策略还会受到障碍高度、距离及自发／反应指令影响，说明任务条件不能省略。[越障起步实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC5013047/)

Schenkman 等对 **9 名健康个体**在受控条件下从椅子起身作全身分析，分出前俯蓄势、离座后的动量转移、伸展和稳定四段。这是解释“离座”与“已稳定站立”之间过程的有用参照，却不是每个人、每把椅子或扶手辅助起身时必须出现的固定四段时长。[Schenkman 等原论文记录与摘要](https://pubmed.ncbi.nlm.nih.gov/2217543/)

**制片推导。** 在站、坐、迈步等动作中，记录“谁承重、哪只脚将离地、何时离座、何时重新稳定”；成片复核时只判断可见的脚底接地、骨盆与躯干轨迹、座椅接触及是否有无支撑的瞬移。具体受力与质心只在有传感器或经校准的三维重建时量化。环境篇负责物体和地面的状态；本篇负责身体如何经过这些支撑切换。

### 目标、轨迹与转身需要分轨

**研究发现。** Flash 与 Hogan 在受控平面内的多关节手臂指向、经过中间目标及绕障实验中，用最小 jerk 模型描述手部末端轨迹，并比较了模型和实测。论文记录了 **9 人**的中间目标实验，也明确涉及实验器械和动作条件。这个模型可提醒制作者检查手的路径和速度变化，却**不能**推出演员的全身动作都应套同一平滑函数；刻意犹豫、碰撞或情绪性制动也未由该实验覆盖。[Flash 与 Hogan 原论文 PDF](https://newmanlab.mit.edu/wp-content/uploads/2017/09/1985-the-coordination-of-arm-movements-an-experimentally-confirmed-mathematical-model.pdf)

一项让 **5 人**直行及绕不同半径弯道的测量发现，直行时眼、头、身体有稳定视线的补偿；转弯时视线和头的方向变化可先于身体轨迹，而躯干未同样提前。这证明“头、躯干、视线永远同帧同角度转向”不适合描述该任务，但样本与弯道条件有限，不能规定所有表演都由眼或头先动。[步行转弯的眼头身体实验](https://pubmed.ncbi.nlm.nih.gov/11204402/) 另一个绕不同角度路径的原始实验也将头与躯干转向作为独立测量对象。[曲线路径转弯实验](https://pubmed.ncbi.nlm.nih.gov/18688604/)

**制片推导。** 将“要去哪里／看哪里”记为空间目标，将根部位移、骨盆／躯干朝向、脚步、头姿、视线分别记为实现轨。允许错峰和补偿，但每个差异要有任务、参考表演或镜头理由；不要随机给各关节加延迟制造所谓自然感。近景看不见脚时，也不能声称仅凭画面证实了起步支撑正确。

### 手势与对白共用一个沟通事件

**研究发现。** Cassell、McNeill 与 McCullough 的语音—手势不匹配实验显示，听者会使用手势提供的补充甚至冲突信息，并在复述中带入手势信息。这个结果说明手势会影响观众接收的叙事信息，但不保证任一手势都能独立传达固定含义。[原论文出版页与摘要](https://benjamins.com/catalog/pc.7.1.03cas)

一项 2024 年原始实验以真实说话者动作捕捉制作三维角色，把目标手势保留原时序、提前 **500 毫秒**、延后 **500 毫秒**或删去，保持音频与面部动画一致；招募 **83 人，排除 2 人后分析 81 人**的话语回忆。原时序和提前的手势相较延后或删去，更有助于回忆关联词；论文同时指出这不等于任意音画延迟的普适阈值，实验测的也不是戏剧表演自然度。[Nirme 等 2024 年原论文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11002957/) 同一团队早先用相关刺激让 **32 人**判断动画自然度，发现目标手势前后偏移 500 毫秒本身未产生显著差异，而显著动作落在语音停顿中时自然度评分下降。两个实验任务不同，不能合并成“所有手势必须提前 500 毫秒”或“时间偏移完全无关紧要”。[Nirme 等 2020 年原论文全文](https://link.springer.com/article/10.3758/s13428-019-01319-w)

**制片推导。** 对有对白的手势，先确定其功能和关联话语：指向哪个目标、展示什么形状、强调哪个语义点、是否刻意与台词矛盾。记录准备、显著动作（stroke）、停留、收回，并标它与相关词句是先于、重叠还是晚于。具体峰值时点依赖声轨、语言韵律、角色意图与镜头；不按均匀节拍在每句台词后机械挥手。没有对白的手势仍需空间目标和故事功能，不能套语音同步研究。

### 风格语言是创作工具，观察一致性需单独检验

Laban 的《The Mastery of Movement on the Stage》及其后续修订版是演员／舞蹈动作探索的原著，可提供动作方向、时间、力度与流动等**创作词汇**；它不是受控实验，不可据此断言某种动作质量必然代表某种心理。[原著版本记录](https://openlibrary.org/books/OL5328154M/The_mastery_of_movement.) 一项使用 Laban 动作分析的原始一致性研究让受训编码者评判舞者演出的两类手势，发现空间与分句相关维度比 Effort 维度更容易取得一致；这提醒制片卡优先写可见方向和阶段，再谨慎使用“沉重”“急促”等质量词。[Laban 编码一致性原论文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0218179)

Disney Animation 的官方流程把时间、清晰调度、预备动作、跟随与次要动作列为角色动画实践原则。这是**制作实践**，不能与起步力学的“预期姿势调整”混为同一人体机制；动画中适当夸张也不是所有真人风格镜头的标准。[Disney Animation 官方动画流程](https://www.disneyanimation.com/process/animation/)

## 将理论写成可执行的肢体表演卡

### 动作单位与分轨

一次身体动作从**任务**而非“姿势标签”开始。最小单位是可观察的目标变化，例如“右脚从支撑变为摆动并落地”“手从身体旁到门把手前”“躯干转向说话者”。每个单位可记录：基线 → 准备或定向 → 发起 → 执行／调整 → 目标到达或受阻 → 稳定、释放或转入下一动作。并非每个单位都有单一峰值；步行往往是重复步态周期，坐站是支撑关系变化，手势可有停留和重复显著动作。这是**制片标注约定**，不是普遍生理阶段表。[起步研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5546309/)、[坐站研究](https://pubmed.ncbi.nlm.nih.gov/2217543/)

| 分轨 | 需要记的可观察信息 | 常见冲突 |
| --- | --- | --- |
| 支撑与姿态 | 身体基线、脚／座椅／扶手的接触、承重趋势、是否稳定 | 脚已离地但重心和另一支撑没有接续；普通视频不可量化力 |
| 根部与路径 | 人物整体在场景中的位置、移动方向、停点 | 镜头平移被误作人物走动；脚滑而身体根部前进 |
| 骨盆／躯干／肩 | 朝向、俯仰、旋转及与脚和头的关系 | 身体各段机械锁死或无理由断裂 |
| 四肢末端 | 脚步落点、手的空间目标、运动方向和停留 | 手和目标失靶；关节长度跨帧变化 |
| 视线／头部 | 看向谁或什么、何时转移、是否与转身协调 | 头转后视线丢失目标；用身体朝向假装眼神已对准 |
| 声轨／手势 | 真正音频、相关词句、手势准备／显著动作／收回 | 台词含义与指向冲突；固定频率挥手 |
| 面部与镜头 | 面部事件、景别、遮挡、剪辑点 | 近景要求验收不可见的脚；镜头切换造成伪连续性 |

所谓“动作质量”在卡中写成**可看见的变化**：例如“手在接近目标前减速，手指在目标旁停留”，而不是只写“优雅”或“慌张”。当故事需要突然制动、犹豫或重复尝试时，标出该事件；不能把所有突变一概抹平。Flash 与 Hogan 的平滑轨迹模型只支持特定目标导向手臂任务，不能代替表演选择。[原始手臂轨迹实验](https://newmanlab.mit.edu/wp-content/uploads/2017/09/1985-the-coordination-of-arm-movements-an-experimentally-confirmed-mathematical-model.pdf)

### 输入、输出与冲突决策

未来 SKILL 收集：人物体型及行动特征（若已提供）、角色任务、外部触发、起始与结束姿态、景别与时长、场景空间目标、可见地面／道具／人、对白或授权声轨、可用参考表演、生成输入通道。缺少时长时先给相对顺序；没有真实声轨时只能定位语义节拍，不承诺词音对齐；没有脚部画面时把步态验收标为“不可观察”。人物行动能力未知时不默认每人有相同步幅、关节活动范围或起身方式。

输出一张卡时按下列顺序：

1. **事件与角色任务**：角色收到了什么信息，想完成什么可见行动；将“观众应读出什么”另列为目标解读，不伪称动作能读心。
2. **身体及场景基线**：人物位置、支撑、身体朝向、手的位置；环境对象的前状态、空间坐标与镜头遮挡。
3. **动作事件链**：每个单位写目标、参与身体部分、准备／执行／调整／结束条件；用先于、重叠、持续到等相对关系联结。
4. **分轨与约束**：根部路径、脚／支撑、躯干、手、头眼、声轨、面部及镜头；若抓取或碰撞，将接触与物体响应交给环境篇同一事件账本。
5. **可见性与控制能力**：写关键帧和整段观察点；文字、参考帧、驱动片、可编辑骨架只是候选输入，实际时间／接触精度必须以目标工具输出实测。
6. **冲突处理与变体**：如台词要求同时双手持物又大幅双手示意，须改成一手、先放下物体或换镜头；若两方案含互斥行动，分版本比较，不合并进一段提示。

简式记录可写作“事件 E：听到呼叫；任务：去回应；基线：坐在椅上，双脚接地；空间目标：右侧画外人；阶段：转眼与头 → 前俯离座 → 伸展站稳 → 起步；支撑：椅座＋双脚 → 双脚 → 单脚交替；视线／声轨：先看画外人，无对白；环境前后：椅子原位；镜头：全身可见；结束：走出两步后停；证据：阶段受坐站／起步研究启发，具体相位待测”。这只是制片卡，不是模型接口声明。[坐站研究](https://pubmed.ncbi.nlm.nih.gov/2217543/)、[起步研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5546309/)

## 两个情境时间线：全部秒数均为待测假设

**情境 A：接到点名后起身，迈向右侧画外人，听到“等等”后停步。** 假设固定机位全身镜头，片长 7 秒，无道具手部交互。空间目标和椅子前后状态由环境篇的事件账本接收。下表时间仅用于制作试镜；绝无论文保证每人应按这些秒数行动。

| 时间假设 | 外部事件／任务 | 身体、视线和支撑 | 镜头验收 |
| --- | --- | --- | --- |
| 0–1.0 秒 | 坐着听到点名，辨认声音来源 | 双脚接地、椅座仍承重；眼与头转向右侧画外人，躯干可略迟 | 初始支撑、目标方向清楚；不要求全身先同步转 |
| 1.0–2.4 秒 | 决定起身 | 躯干前俯；脚维持接地；离座后转为双脚支撑 | 椅座接触消失有可见过程，骨盆不瞬移 |
| 2.4–3.3 秒 | 站直并稳定 | 髋膝伸展，身体到达站姿；**本镜头选择**短暂停稳再迈步，也可根据参考表演让起身末段接续迈步 | “离座”与“站稳”在本版本分开观察，镜头可见双脚；停稳不是普遍必要阶段 |
| 3.3–5.2 秒 | 向右迈出约两步 | 根部位移、脚落点和躯干方向保持因果关系；视线指向目的地或说话者 | 每一步支撑交替与位移一致；无脚滑 |
| 5.2–7.0 秒 | 画外人说“等等”，角色停止 | 声音发生后才减速；最后一步落地并稳定；头眼可回到说话者，身体可保留部分朝向 | 不提前停步；脚、根部、头眼的结束状态可复核 |

研究只支持区分坐站、起步和转弯的运动组织；上表中的相位顺序与秒数仍是**创作设计**，需要获授权的演员参考与生成输出检验。[坐站原论文](https://pubmed.ncbi.nlm.nih.gov/2217543/)、[起步原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5546309/)、[眼头身体协调原论文](https://pubmed.ncbi.nlm.nih.gov/11204402/)

**情境 B：角色说“先看这边”，手指向左侧位置。** 假设中景、4 秒，声轨已有授权。0–1 秒保持手在身体旁；1–2 秒说“先看”，手开始准备并看向左侧目标；2–3 秒说“这边”时指示动作显著部分与词句重叠，目标在镜内清楚；3–4 秒手回落或维持，以对方是否开始看目标来决定。这里的秒数与词位全是**假设**，真正制作须按录音和角色动作重排。相关实验只说明手势信息与语音关系会影响回忆，并不证明这个中文词组的最佳同步点。[手势时序原始实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC11002957/)、[语音—手势不匹配原始实验](https://benjamins.com/catalog/pc.7.1.03cas)

## 失真检查：看帧，也看动作之间

以下是**拟用于人工复核的检查表**，不是测得的模型错误率。每项至少保留基线、准备、接触／支撑切换、完成与结束附近的画面；有对白时叠加声轨。

| 失真 | 可观察的判据与检查方法 |
| --- | --- |
| 脚滑／支撑漂移 | 标记每只脚接地片段；接地脚在人物整体移动时无故相对地面滑行 |
| 离座或起步瞬移 | 座椅接触、骨盆高度、支撑脚在相邻帧突变；按阶段正常速与逐帧看 |
| 根部、关节或骨长断裂 | 躯干、手、脚路径突跳，四肢长度／关节关系跨帧变形；同人物与相机参照比较 |
| 全身机械同起同止 | 头、躯干、两手、两脚不论任务均同帧启动／停住；检查各轨事件理由 |
| 无端过度平滑 | 应有犹豫、受阻或突然制动的事件被插值抹掉；对照事件表与参考表演 |
| 无端抖动或重复 | 手腕、肩、膝在静止任务中持续随机摆动；检查是否有声轨或空间目标 |
| 转向目标失靶 | 视线、头、躯干、脚最终目标互相矛盾，且无角色任务解释；将目标点标在场景图 |
| 手势与对白错位 | 指示动作指错对象，或显著动作落在不相关词句之后；对齐录音和手轨 |
| 动作与镜头混淆 | 人物相对背景未移动而画面位移，或剪辑改变角度被计作转身；分看背景和身体 |
| 景别不能证明动作 | 近景遮住脚或座椅，仍宣称起步与离座支撑准确；标“不可观察”并加全身复核 |
| 静帧对、整段不通 | 姿势峰值可读，但进入、支撑转换或退出失败；静帧与整段分别盲评 |
| 情绪动作定式 | 每次“害怕”都缩肩、每次“自信”都叉腰；同角色跨情境比较其任务与行动结果 |

其中脚滑、关节断裂、镜头混淆、身份漂移是**生成质量检查**，不是以上人体实验报告出的模型错误率。支撑切换和手势对齐受到原始研究启发，但具体容忍阈值必须按镜头、帧率、标注可靠性与目标工具确定。[起步研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5546309/)、[手势时序研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11002957/)

## 可证伪的验证方案

目前没有目标视频生成模型的样本，因此只给待执行协议。先以获授权的演员视频或可编辑角色建立参照，固定身份、场景、声轨、景别及镜头；一次只改一个编排条件。至少两位编码员独立标注可见事件与“无法判断”，分歧复核；观众在不知道方案的条件下分别评判动作目标是否读得出和整体是否自然。Laban 编码一致性研究也提示，主观动作质量词需做一致性校验，不能视为客观真值。[Laban 编码原论文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0218179)

| 待验证假设 | 对照变量 | 分开记录的结果 |
| --- | --- | --- |
| 写出支撑切换比只写“站起来”更稳定 | 同镜头同人同椅；只改起身提示的阶段描述 | 离座／站稳顺序、脚与座椅接触连续性、整段可读性 |
| 有目标的头眼躯干编排比全身同帧转更可读 | 同转弯任务；只改分轨相位 | 目标定位、身体方向、观众读出的行动意图与自然度 |
| 手势与相关话语成事件关系比固定节拍挥手更清楚 | 同声轨；只改手势功能与相位 | 指示目标命中、词句关联、观众复述内容 |
| 参考表演／可编辑动作比纯文字更能保留支撑和相位 | 同内容、同目标工具；改变输入通道 | 足接地、关节连续性、事件时间误差、身份稳定性 |

不能用“情绪标签命中”代替动作物理连续性，也不能只用静帧好看来证明整段表演成立。无法看见脚、手或目标对象时，记录遮挡或证据缺失，不把动作判成“零”。任何自动姿态追踪或接触检测都先和人工标注校准，再分景别与遮挡条件汇报错误。

## 尚未解决的边界

1. 原始运动研究多发生在实验室、特定年龄或健康人群；动作障碍、不同体型、扶手辅助、重物、舞台风格和文化习惯都可能改变具体运动。本文没有这些条件的通用阈值。
2. Laban 与动画原则能提供创作维度，不能仅凭术语推断真实情绪或观众必然的解释。手势与语言的研究主要关注信息处理，不等于短剧表演自然度。
3. 普通二维画面难以直接测质心、力和精确关节角；相机、遮挡、衣物与剪辑会改变可见性。需要三维重建或传感器时应另标数据条件。
4. 纯文字、端点帧、驱动片和曲线输入的能力随目标工具版本变化。本文没有完成模型接口核验、付费生成或盲评，不保证任何一项能准确执行毫秒级动作、脚底接触或跨镜头身份。
