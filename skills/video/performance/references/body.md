# 肢体表演：支撑、路径、转身与手势

本文件中的秒数、强度都是创作假设。纯文字提示词只能表达各阶段的意图，不能保证骨架、脚底接触或具体时点。面部局部动作见 [face.md](face.md)，人与物体、场景之间的接触见 [environment.md](environment.md)。三份参考共用同一条事件线，不要各写一套互相矛盾的时间表。

## 核心写法

- 肢体表演从**任务**开始，而不是从“姿势标签”开始。先写角色要完成的可见行动；“紧张”“自信”是希望观众读出的解读，不要一对一套成缩肩、叉腰。
- 关键姿态要看得清，走到这个姿态的过程也要读得出来，两者都要写。
- “动作质量”要写成看得见的变化。例如写“手在接近目标前减速，手指在目标旁停留”，不要只写“优雅”“慌张”。
- 故事需要突然制动、犹豫或重复尝试时，把它作为一个事件写出来，不要被平滑的插值抹掉。
- Laban 动作词汇（方向、时间、力度、流动）和动画原则（预备、跟随、次要动作）是创作工具，不能据此断言某种心理。真人风格不照搬动画式的夸张。

## 动作单位与分轨

最小单位是一个可观察的目标变化，例如“右脚从支撑变为摆动再落地”“手从身侧伸到门把前”“躯干转向说话者”。一个单位可以写成：

**基线 → 准备或定向 → 发起 → 执行 / 调整 → 到达目标或受阻 → 稳定、释放或转入下一个动作**

不是每个单位都有单一峰值：步行是重复的周期，起坐是支撑关系的变化，手势可以有停留和重复。

| 分轨 | 写什么 | 常见冲突 |
| --- | --- | --- |
| 支撑与姿态 | 身体基线；脚、座椅、扶手的接触；承重趋势；是否稳定 | 脚已离地，但重心没有接续到另一个支撑 |
| 根部与路径 | 人物在场景中的位置、移动方向、停点 | 镜头平移被误当成人物走动；脚在滑而身体前进 |
| 骨盆 / 躯干 / 肩 | 朝向、俯仰、旋转，与脚和头的关系 | 各段机械锁死，或无理由断裂 |
| 四肢末端 | 脚步落点、手的空间目标、运动方向、停留 | 手和目标错位；肢体长度跨帧变化 |
| 视线 / 头 | 看向谁或什么、何时转移、是否与转身协调 | 头转了但视线丢失目标 |
| 声轨 / 手势 | 台词、相关词句、手势的准备 / 显著动作 / 收回 | 指向与台词含义冲突；固定节拍挥手 |
| 面部与镜头 | 面部事件、景别、遮挡、剪辑点 | 近景要求验收看不见的脚 |

## 支撑转移

- **起身**依次写：躯干前俯 → 臀部离座（椅面停止承重）→ 伸展 → 双脚承重、站稳。“站稳”与“迈步”可以分开，也可以衔接。
- **坐下**反向写：何时接触椅面，椅子是否保持原位。
- **起步**：脚离地前可以有重心预备，但不是每次都要有可见的预备动作。
- 扶手、拄杖、扶桌属于角色的具体条件，不要默认每个人都这样做。行动能力未知时，不默认所有人步幅、起身方式都相同。

## 目标、转身与路径

- 把“要去哪里 / 看哪里”写成空间目标，根部位移、躯干朝向、脚步、头姿、视线分别作为实现方式。
- 转弯时视线和头可以先于身体，但不强制“眼永远先动”。
- 允许错峰和补偿，每个差异都要有任务或镜头上的理由，不要随机给关节加延迟来制造“自然感”。

## 手势与对白

- 先定手势的**功能**：指向哪个目标、展示什么形状、强调哪个语义点，还是刻意与台词矛盾。
- 写出准备、显著动作、停留、收回四段，并写明显著动作与相关词句的关系：先于、重叠还是晚于。常见写法是让显著动作与相关词重叠，或略早于它。
- 显著动作不要落在语音停顿里，除非这是刻意安排。不要在每句台词后机械地挥手。
- 没有对白的手势也要有空间目标和故事功能。

## 输出顺序与冲突变体

1. 事件与角色任务，以及希望观众读出的解读（单独列出，不假装动作能读心）。
2. 身体与场景基线：位置、支撑、朝向、双手在哪里。
3. 动作事件链：每个单位的目标、参与部位、结束条件，用先后关系串起来。
4. 分轨与约束。涉及抓取或碰撞时，交给 environment 的接触与状态账本处理。
5. 可见性：写明哪些关键阶段在画内。
6. 冲突与变体。例如台词要求双手持物，同时又要大幅双手比划，就改成一只手、先放下物体，或换镜头。互斥的方案分版本写，不合并进同一条提示词。

示例（起身迎人）：“听到点名 → 眼与头转向右侧画外人，躯干稍晚 → 前俯离座 → 伸展站稳 → 向右迈两步 → 听到‘等等’后减速，最后一步落地站稳，头眼回到说话者。支撑：椅面＋双脚 → 双脚 → 单脚交替 → 双脚。”

## 肢体失真清单

1. **脚滑**：接地的脚在人物移动时相对地面滑行。
2. **离座或起步瞬移**：座椅接触、骨盆高度、支撑脚在相邻帧突变。
3. **根部、关节或骨长断裂**：路径突跳，四肢长度跨帧变形。
4. **全身机械同起同止**：头、躯干、双手、双脚同一帧启动或停住。
5. **过度平滑**：应有的犹豫、受阻、突然制动被抹掉。
6. **抖动或重复**：静止时手腕、肩、膝随机摆动。
7. **转向失靶**：视线、头、躯干、脚的最终目标互相矛盾。
8. **手势与对白错位**：指错对象，或显著动作落在不相关的词句之后。
9. **动作与镜头混淆**：人物相对背景没动，画面却在移动。
10. **景别不足**：近景看不到脚或座椅，仍宣称起步、离座正确。
11. **单帧对、整段不通**：姿势峰值可读，进入、支撑切换或退出却失败。
12. **情绪动作定式**：每次“害怕”都缩肩，每次“自信”都叉腰。

## 证据边界

- Johansson 1973：只保留运动的少数光点，观察者仍能读出行动；不支持“某种情绪对应某种动作”的配方。https://robotics.usc.edu/~maja/teaching/cs584/papers/Johansson_Visual_Perception.pdf
- Atkinson 等 2004：动态的身体表达通常比静帧更易分类，但夸张程度的效果因情绪类别而异。https://journals.sagepub.com/doi/10.1068/p5096
- Lu 等 2017：自发起步的预期姿势调整常有成分缺失（24% 的试次）。https://pubmed.ncbi.nlm.nih.gov/28651215/
- Schenkman 等 1990：起身可以分为前俯、离座、伸展、稳定四段，但不是固定时长。https://pubmed.ncbi.nlm.nih.gov/2217543/
- Flash & Hogan 1985：受控手臂任务的平滑轨迹，不外推到全身表演。https://newmanlab.mit.edu/wp-content/uploads/2017/09/1985-the-coordination-of-arm-movements-an-experimentally-confirmed-mathematical-model.pdf
- 步行转弯的眼、头、身体协调研究（2001、2008）：转弯时视线和头可以先于躯干，样本有限。https://pubmed.ncbi.nlm.nih.gov/11204402/
- Cassell 等 1999；Nirme 等 2020、2024：手势会影响听者接收的信息；同步或提前的手势有助于回忆，落在停顿中的显著动作会降低自然度评分。“500 毫秒”只是实验操纵的数值，不是阈值。https://pmc.ncbi.nlm.nih.gov/articles/PMC11002957/
- Laban 1950；LMA 一致性研究 2019：空间与分句维度比 Effort 维度更容易取得编码一致。https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0218179
- Disney Animation 官方流程：动画原则是制作实践，不是人体力学。https://www.disneyanimation.com/process/animation/
