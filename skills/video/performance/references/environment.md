# 环境交互：对象、接触、支撑与后果

本文件中的时点都是创作假设。纯文字提示词只能表达各阶段的意图，不能保证手指位置、接触时点、力量或物理状态。人体自身的运动见 [body.md](body.md)，面部动作见 [face.md](face.md)。

## 核心写法

先定义场景里**有什么**、角色要**改变什么**，再写朝向、接近、接触、操纵与释放，并记录交互之后环境的状态。不要从画面风格去猜重量、摩擦或力的数值。

- **可行动性取决于身体与空间的关系**：写“穿过门”之前，先写清门是否开着、通道是否被占、人物是否携物、目标在门的哪一侧。空间要求侧身、让路或移开障碍时，把这些调整写出来。椅子可供坐下，角色也可以选择绕过它。
- **视线服务于当前操作，也为下一步预备**：给出具体的注视目标，比如杯柄、门把、门缝、接物者的手、落座处，不要只写“看向前方”。看、伸手、转身可以重叠。镜头看不到眼睛时，用头部朝向、手的目标和物体反应来交代。
- **抓握有过程**：手在移向目标时逐渐成形，先接触，然后物体才离开支撑面；移动中物体相对手保持稳定；放下时物体先接触新的支撑面，手再松开。不要写成手还远着物体就跟着动。
- **递物是双方共同改变持有关系**：写明谁先持有、谁先到达交接点、双方是否同时接触、谁先松手、谁把物体带走。直接手递手可以安排短暂的共同接触；放在桌上让对方再拿、抛掷、剪辑省略，都是不同的机制，要写明物体的中间支撑。
- **观众理解的是有层次的事件**：上层写“把水杯递给同伴”，下层写“定位杯柄 → 抓取 → 离桌 → 移到交接点 → 共同接触 → 松手”。下层可以被剪掉或遮挡，但物体的前后状态必须自洽。

## 统一表演卡字段

面部、肢体、环境共用同一套字段。每个字段可以写文字、先后关系或区间，不需要伪造精确秒数。

| 字段 | 写什么 | 示例：起身去拿门边的杯子 |
| --- | --- | --- |
| 外部事件 | 角色看到或听到的变化 | 门铃响，杯子在门边桌上 |
| 角色任务 | 可观察的目标 | 起身、拿杯、走向门 |
| 身体基线 | 当前姿势与运动状态 | 坐在椅上，双脚落地，右手空着 |
| 空间目标 | 人、物、落点与路径 | 杯柄朝右，门在画面左后方 |
| 动作阶段 | 可先后、可重叠的变化 | 前倾、离座、看向杯柄、伸手、提杯、转身 |
| 视线 / 声轨 | 看向哪里，声音何时出现 | 门铃响后先看门，再看杯柄 |
| 接触 / 支撑 | 谁接触谁，谁在承重 | 椅面＋双脚 → 双脚；桌面托杯 → 右手持杯 |
| 环境前后状态 | 物体状态的变化 | 杯子离开桌面；椅子不动；门仍关着 |
| 镜头可见性 | 哪些证据在画内 | 中景可见离座和抓杯 |
| 结束条件 | 停止、残留或进入下一个事件 | 右手持杯站稳，准备开门 |

面部的“起始 / 峰值 / 释放”记录局部动作；本文件的“首次接触 / 支撑转移 / 物体释放”记录关系状态的改变。两者可以错峰。

## 对象卡、接触图与状态账本

- **对象卡**：每个与行动相关的对象记录标识、类型与外观、初始位置和朝向、可操作的部位、是否可移动或铰接、初始状态。材质和重量只在剧本明确时才写。
- **接触与支撑**：写成“角色部位 ↔ 对象部位”，例如“右手 ↔ 杯柄”“杯底 ↔ 桌面”“双脚 ↔ 地面”。状态依次为未接触、接近、接触、承重或施力、释放。支撑可以重叠：手已经碰到杯子，杯底还在桌上；递物时双方同时持有。
- **状态账本**：按“对象 | 前状态 | 触发动作 | 可见或可听反馈 | 后状态 | 下一段继承”的格式记录。例如：“门 | 关 | 按下门把并推门 | 门扇旋开 | 开 | 下一段仍开着”。声音可以交代画外事件，但不能证明画内物体已经移动。

## 交互的相对时间线

候选链：**发现或确认目标 → 调整位置与朝向 → 接近 → 建立接触 → 施力或承重转移 → 观察反馈 → 释放或维持 → 环境后状态**。

- 阶段可以重叠，失败后可以回退，用不到的阶段可以省略。
- 先后关系写成 before / after / overlap / until，例如：“手触到杯柄 before 杯底离桌”“接收者碰到杯身 overlap 递交者仍持杯”“门扇开启 after 推门”。
- 剪辑可以省略中段，但下一段里物体的位置和持有者必须从上一段的结束状态继承。

## 五个情境

| 情境 | 前状态与任务 | 关键接触与可见过程 | 后状态与易错处 |
| --- | --- | --- | --- |
| 取杯放下 | 杯子在桌上，要移到书旁 | 视线定位可握的部位 → 手在接近中成形 → 接触后杯底才离桌 → 移动中杯随手稳定 → 杯底先落桌，手再松开 | 杯子停在新位置不动。检查手杯漂移、杯底悬空、液位无故变化 |
| 开门进入 | 门关着，人在门外 | 接近门把 → 触碰 → 门扇沿铰链方向转开 → 调整路径或侧身通过 → 通过前或通过中松手 | 人在门内，门的开闭状态延续。检查门扇穿过人物、下一段门无故复位 |
| 坐下后起身 | 坐在椅上，双脚着地 | 前移，从椅面离开，支撑由椅面＋双脚转为双脚；如果借扶手，写明扶手的接触与释放 | 椅子原位。近景不能证明支撑转移。检查臀部穿椅、椅子跟着起身 |
| 双人递物 | 甲拿书，乙两手空着 | 甲递到乙可达的位置 → 乙接触并握住 → 短暂共同持有 → 甲松手 → 乙带走；双方各有明确的注视目标 | 持有者由甲变成乙。检查甲过早松手导致书悬空、书在两手之间瞬移 |
| 受阻后修正 | 想拉开抽屉，前面有椅子挡着 | 定位拉手 → 尝试拉 → 可见的阻力或碰撞反馈 → 停下看向障碍 → 挪开椅子或从侧面拉 → 再尝试 | 障碍解决前抽屉一直关着，椅子的新位置保留。检查抽屉穿过椅子、已经打开却又重试 |

## 失真清单与验收顺序

1. **目标漂移**：手的接触点、门把或杯柄在相邻帧不稳定；看不出角色在针对哪个物体。
2. **接触缺口或穿透**：首次接触、持物、释放时手与物体分离或互相穿过；物体在无人持有、没有支撑时悬空跟随。
3. **支撑矛盾**：离座、落座、离桌、落桌时承重关系不成立。
4. **物体状态跳变**：门的角度、杯中液位、衣物形态突变；跨段的位置、开闭状态、持有者没有继承下来。
5. **视线与行动脱节**：角色从没发现障碍，却准确地避开了。
6. **反馈缺失**：推门、拉抽屉、碰撞、滑脱之后物体没有相应变化；修正动作没有可见或可听的原因。
7. **镜头证据不足**：关键交接或支撑点被裁掉或遮挡。

验收顺序：先按状态账本核对每次状态转移，再看接触与支撑的关键帧，最后以正常速度看角色任务是否清楚。被遮挡的阶段记为“无法判断”，不算通过。

## 证据边界

- Gibson 1979；Warren 1984；Warren & Whang 1987：可行动性取决于身体尺度与空间尺度的关系，研究中的门洞阈值不能通用。https://pubmed.ncbi.nlm.nih.gov/2958586/
- Land 等 1999；Hayhoe 等 2003：日常任务中视线多落在正在操作的物体上，同时也在为下一步做计划；不支持“视线总严格先于手”。https://www.cis.rit.edu/pelz/scanpaths/papers/teamaking-land-mennie-rusted-1999.pdf
- Jeannerod 1984；Johansson & Westling 1984：手的运输与成形在时间上重叠；握力随负载协同变化，但力无法从普通视频读出。https://pubmed.ncbi.nlm.nih.gov/15151851/
- Schenkman 等 1990：起身时的离座支撑转移。https://pubmed.ncbi.nlm.nih.gov/2217543/
- Döhring 等 2020；Kato 等 2019；Kutz 等 2023：递物时双方的握力协调，交接点随搭档条件调整；不给出固定的距离或眼神规则。https://pmc.ncbi.nlm.nih.gov/articles/PMC7759571/
- Zacks 等 2001：观察者会把日常活动分割成粗细层级对应的事件；该研究没有检验 AI 视频的连续性。https://www.tc.columbia.edu/faculty/bt2158/faculty-profile/files/grememberingandcommunicatingstructureinevents.pdf
