# 面部表演：动作词汇、情绪速查与时序

## 怎么用这份参考

1. **先查剧情**：在“剧情速查”里找到最接近的情境，确定触发事件和反应的先后。
2. **再查情绪与程度**：在“情绪速查”里按程度（微弱 / 中等 / 明显）取各区域的可见变化。
3. **用区域词汇落笔**：按“面部区域词汇”写成精确的中文动作描述。
4. **排时序**：按“生命周期”和“相对时序”安排起始、峰值、释放、残余，再与视线、头、口型错开。
5. **自检**：按文末的失真清单检查。

三条边界：

- 表中的 AU 编号只是内部索引，**不写进提示词**。通用视频模型没有 AU 参数，提示词里写的是可见的动作描述。
- 速查表给的是**典型候选**，不是公式。实验中，人们在相应情绪下做出这些典型配置的平均比例只有约 19%（各情绪在 15% 到 25% 之间）。同一张脸在不同情境下会被读成不同意思，所以要先写事件和情境，再用表情支撑。
- 秒数和强度都是创作假设。纯文字提示词只能表达阶段意图，不能保证某个时点出现某个动作。

## 面部区域词汇

提示词要写“哪个部位、往哪个方向、动多少”，不要写“开心的脸”。以下写法来自 FACS 公开动作名称（CMU 整理的 1978 版词表），只作创作简述，不是 2002 手册的正式判据。

| 区域 | 动作 | 推荐写法 | 易混淆 | 索引 |
| --- | --- | --- | --- | --- |
| 眉 | 内眉上提 | 眉头内侧向上抬，眉心上方出现短横纹，眉形呈“八”字 | 整条眉上抬 | AU1 |
| 眉 | 外眉上提 | 眉毛外侧向上抬 | 抬头造成的视觉变化 | AU2 |
| 眉 | 整眉上抬 | 整条眉毛上抬，额头出现横纹 | — | AU1+2 |
| 眉 | 眉压低收拢 | 眉头压低并向中间收拢，眉间出现竖纹 | 眯眼、固有眉间纹 | AU4 |
| 眼 | 上眼睑抬起 | 上眼睑抬起，眼裂变大，虹膜上方露出眼白 | 抬眉、向上看 | AU5 |
| 眼 | 颊部上提 | 脸颊向上推，下眼睑下方鼓起，眼角出现细纹 | 眼睑收紧 | AU6 |
| 眼 | 眼睑收紧 | 下眼睑绷紧上推，眼睛变窄但没有闭上 | 颊部上提、眨眼 | AU7 |
| 眼 | 闭眼 / 眨眼 / 单眼眨 | 双眼闭合停留 / 一次快速眨眼 / 单眼眨 | 三者是不同的事件 | AU43 / 45 / 46 |
| 鼻 | 皱鼻 | 鼻梁皱起，鼻翼上提 | 上唇上提 | AU9 |
| 口 | 上唇上提 | 上唇中部向上提，露出上齿 | 皱鼻、发音口型 | AU10 |
| 口 | 嘴角上提 | 嘴角向外上方牵拉 | 嘴角横拉、单纯露齿 | AU12 |
| 口 | 嘴角收紧 | 嘴角向内收紧，出现小凹陷 | 嘴角上提、唇收紧 | AU14 |
| 口 | 嘴角下拉 | 嘴角向下拉 | 下巴上推、低头 | AU15 |
| 口 | 下巴上推 | 下巴皮肤上推起皱，下唇被顶起 | 双唇相压 | AU17 |
| 口 | 嘴角横拉 | 嘴角向两侧水平拉开，嘴唇变扁 | 嘴角上提、说话口型 | AU20 |
| 口 | 唇收紧 | 唇缘收紧变薄 | 双唇相压 | AU23 |
| 口 | 双唇相压 | 上下唇互相压紧 | 唇收紧、下巴上推 | AU24 |
| 口 | 双唇分开 / 下颌下落 / 大张口 | 双唇微分 / 下颌放松下落 / 嘴大幅张开 | 说话口型 | AU25 / 26 / 27 |
| 头与视线 | 转、俯、仰、侧倾；视线方向 | 单独写成头部动作与注视目标 | 相机运动 | AU51–58 / 61–64 |

轻蔑类动作是**单侧**的，要写明是人物自己的左侧还是右侧。其余动作默认双侧，除非角色设定有依据。

## 程度怎么写

| 程度 | 参与区域 | 幅度与时长 | 景别 | 常见写法 |
| --- | --- | --- | --- | --- |
| 微弱 | 通常 1 个区域为主，其余保持基线 | 几乎看不出到轻微；峰值短，常被压住或很快释放 | 需要近景或特写，并有清楚的触发事件 | “几乎看不出的”“轻微”“一闪而过”“随即收住” |
| 中等 | 2–3 个区域协同 | 清楚可见，有短暂的平台 | 近景到中景 | “明显”“停住”“逐渐加深” |
| 明显 | 典型组合的大部分区域，常带头部、呼吸、声音或身体 | 幅度大，释放慢，残余长 | 中景也能读出 | “大幅”“整张脸”“伴随……”“久久没有散去” |

依据与边界：强度越高，观众越容易认出、判断也越快（Hess 等 1997；Wingenbach 等 2016）。“低强度参与的区域更少”是从幅度研究推导出的写法，不是论文直接给出的数字。微弱程度离不开情境：只写“微弱的悲伤”而没有触发事件，观众大概率读不出来。

## 情绪速查：程度梯度

写法：挑选对应程度那一格，把其中的动作按“剧情速查”里的先后顺序展开，每个动作都要有起落，不要一次全部叠满。**依据**列的含义：

- **原型**：Du 等 2014 的摆拍原型（230 人，表情是摆出来的，括号内为出现比例）。
- **展示**：已发表的特定情绪展示研究。
- **H**：制片推导，没有面部原型证据，按需调整。

| 情绪 | 微弱 | 中等 | 明显 | 依据 |
| --- | --- | --- | --- | --- |
| 愉快 | 嘴角几乎看不出地上提，闭口，其他部位不动 | 嘴角明显上提，双唇微分露出一点牙齿，脸颊上推，下眼睑微鼓 | 嘴角大幅上扬，张口露齿，脸颊高推挤窄眼睛，眼角细纹；伴随笑声、头后仰、肩膀抖动 | 原型：嘴角上提＋双唇分开；颊部上提约 51% |
| 礼貌 / 社交笑 | 嘴角轻提后停住，眼周不动 | 嘴角上提并维持较久，脸颊少量参与，视线礼貌地停在对方身上 | 露齿笑停留过久、起落整齐，显得僵硬（用于“假笑”） | 展示：同一笑形可被读成愉快、礼貌或尴尬（Ambadar 等 2009）；具体写法为 H |
| 想笑又忍住 | 嘴角有上提的迹象，随即双唇轻压 | 嘴角上提与双唇相压交替，视线移开，鼻腔轻呼一口气 | 嘴角压不住地上扬，用手遮嘴或低头，肩膀轻颤 | H（取自调研候选组合） |
| 尴尬 / 害羞 | 视线下移，嘴角轻提后马上抿住 | 视线移开 → 压住笑 → 不带眼周的笑 → 头向下侧转 → 再抿唇 | 在上一格基础上反复移开视线，手摸脸、脖子或头发，脸红 | 展示：Keltner 1995 的尴尬序列（美国样本） |
| 悲伤 | 眉头内侧轻抬，嘴角轻微下沉，视线下落 | 眉头内侧上抬并向中间聚拢（八字眉），嘴角下拉，下巴起皱、下唇被顶起，眼眶发红湿润 | 下唇颤抖，嘴角大幅下拉，张口抽泣，眼睛挤紧或闭上，流泪，低头，肩膀随呼吸抽动 | 原型：眉压低收拢＋嘴角下拉；内眉上提约 60%，下巴上推约 67% |
| 失望（仍维持礼貌） | 笑容僵住，嘴角轻落，眉内侧一抬 | 视线短暂落低，嘴角下沉后抿唇压住，再抬眼回到对方 | 压不住：下巴起皱，喉结滚动，转开脸 | H（取自调研候选组合） |
| 愤怒 | 眉间轻收，眼睑略紧，双唇闭合，视线锁定对方 | 眉压低、眉间竖纹明显，眼睛变窄，双唇压紧变薄，下颌收紧，鼻孔张大，呼吸变重 | 瞪眼（上眼睑抬起），上唇上提露齿或张口吼，头向前探，颈部绷紧 | 原型：眉压低收拢＋眼睑收紧＋双唇相压；下巴上推约 52%，上唇上提与唇收紧较少出现；“明显”一格为 H 扩展 |
| 压抑怒意 | 原有的笑意先退去，眉间微收 | 眉间收拢、眼睑收紧，双唇压紧但不咬死，呼吸放慢变深 | 下颌咬紧、腮部肌肉鼓起，鼻孔张大，声音压低，眼神一直锁定 | H（取自调研中“被背叛后的压抑怒意”情境） |
| 恐惧 | 眉头内侧轻抬并略微收拢，双唇微张，身体停住、屏住呼吸 | 眉头上抬又收紧（眉形平直紧张），上眼睑抬起露出眼白，嘴角向两侧横拉，嘴张开 | 眉高抬紧收，瞪大眼，嘴大张横拉；头后缩，身体后撤，呼吸急促 | 原型：内眉上提＋眉压低＋嘴角横拉＋双唇分开；外眉上提约 57%，上眼睑抬起约 63% |
| 惊讶 | 眉毛轻抬，眼睛略睁大，双唇轻分，随即回落 | 整条眉毛抬高、额头出现横纹，眼睛睁大，下颌放松、嘴张开 | 眉高抬，眼睁圆，嘴大张；真人片中容易变成漫画效果，要慎用 | 原型：整眉上抬＋双唇分开＋下颌下落；上眼睑抬起约 66% |
| 厌恶 | 鼻翼轻皱或一侧上唇微提，头略后撤 | 鼻梁皱起，上唇上提露出上齿，下唇被顶起，眉头略压 | 皱鼻明显，上唇高提，转头避开，手挡在身前，作呕 | 原型：皱鼻＋上唇上提＋下巴上推；眉压低约 31%，双唇相压约 26% |
| 轻蔑 / 不屑 | 一侧嘴角轻轻收紧上提，随即收回 | 一侧嘴角收紧上提并停住，视线从上往下斜看，下巴微抬 | 在上一格基础上加鼻腔轻哼、翻眼或转开脸 | 展示：单侧嘴角上提＋嘴角收紧（Matsumoto 与 Ekman 的 JACFEE 编码） |
| 疼痛 | 眉间一收，眼睛眯一下，很快恢复 | 眉压低，眼睛挤窄或紧闭，鼻翼皱起，牙关咬紧 | 紧闭双眼，上唇高提露齿，张口吸气或叫出声，身体蜷缩、护住痛处 | 展示：眉压低＋眼周收紧＋皱鼻或上唇上提＋闭眼（Prkachin 1992） |
| 喜出望外 | 眉毛一抬，嘴角随即上提 | 眉毛抬高、眼睛睁大，同时笑开嘴 | 嘴大张笑出声，双手捂嘴或张开双臂 | 原型（复合）：整眉上抬＋嘴角上提＋双唇分开 |
| 悲愤 | 眉间收拢，嘴角下沉并抿紧 | 眉压低收拢，嘴角下拉，眼睑收紧，下巴起皱 | 含泪瞪视，下唇颤抖，声音发紧 | 原型（复合）：眉压低收拢＋嘴角下拉；眼睑收紧约 48%，下巴上推约 50% |
| 惊恐 | 眉毛骤抬，眼睛睁大，屏住呼吸 | 眉高抬，瞪眼露白，嘴角横拉张嘴 | 在上一格基础上身体猛地后撤、尖叫 | 原型（复合）：整眉上抬＋上眼睑抬起＋嘴角横拉＋双唇分开 |
| 憎恶 / 厌恨 | 眉间一收，上唇一侧微提 | 眉压低，上唇上提，眼睑收紧，下巴上推 | 咬牙露齿，眼神死盯，鼻翼张大 | 原型（复合）：眉压低＋上唇上提；眼睑收紧约 57%，下巴上推约 63% |
| 敬畏 / 震撼 | 眉毛轻抬，双唇微分，身体静止 | 眉抬起，眼睛睁大，嘴微张，缓缓呼气，头微仰 | 久久凝视，嘴张着忘了合上，手不自觉地停在半空 | 原型（复合）：整眉上抬＋上眼睑抬起＋双唇分开；嘴角横拉约 62%；头与呼吸为 H |
| 骄傲 | 嘴角小幅上提，下巴微抬 | 小幅笑，头后仰，胸口挺起 | 在上一格基础上叉腰或举起双臂 | 展示：Tracy 与 Robins 2004、2007；只看脸无法可靠识别，必须写身体 |
| 羞愧 | 视线下移，头微低 | 低头，视线落地，不笑，肩膀内收 | 背过身，双手遮脸 | 展示：头低＋视线向下，无笑（Keltner 1995） |
| 怀疑 / 审视 | 眉微压，眼睑略紧，视线停在对象上 | 眉压低收拢，眼睛眯起，嘴唇抿住，头微侧 | 上身后仰拉开距离，一侧眉挑起，冷笑 | H（取自调研候选组合） |
| 焦虑 / 紧张 | 视线游移，抿唇，吞咽一下 | 眉头内侧上抬，咬唇或舔唇，眨眼变多，呼吸浅快 | 眼神慌乱四顾，嘴唇发白颤抖，手部小动作不停 | H |
| 感动 / 含泪而笑 | 眼眶泛红，嘴角轻提 | 眉头内侧上抬的同时嘴角上扬（上半脸悲、下半脸笑），下眼睑湿润 | 笑着流泪，下巴起皱，抬手擦眼 | H（用“混合”规则组合悲伤的上半脸与愉快的下半脸） |
| 如释重负 | 长呼一口气，眉眼放松 | 肩膀下沉，闭眼一瞬再睁开，嘴角轻提 | 身体松垮，靠在旁边的物体上，笑出声 | H |
| 疲惫 / 无聊 | 眼睑略微下垂，视线失焦 | 上眼睑半垂，缓慢眨眼，嘴角松弛，头支在手上 | 打哈欠（嘴大张），眼睛几乎闭上，身体瘫坐 | H |

## 剧情速查

先写事件，再用上表的程度格落地。箭头表示先后，“/”表示可选分支。

| 剧情 | 常见读法 | 推荐反应过程 | 程度选择 |
| --- | --- | --- | --- |
| 收到好消息（录取、中奖） | 喜悦、喜出望外 | 视线锁定消息源 → 辨认时短暂停顿、眉眼一抬 → 眉眼回落 → 嘴角逐渐上提 → 平台 | 克制型角色或公共场合用微弱到中等；独处或性格外放的角色用明显 |
| 意外重逢 | 惊讶转为喜悦或感动 | 视线停在对方身上 → 愣住、呼吸停顿 → 眉内侧抬起的同时嘴角上扬 → 眼眶湿润 | 久别的用“感动”，偶遇的用“喜出望外” |
| 噩耗、坏消息 | 震惊转为悲伤 | 读完或听完 → 整个人僵住、屏住呼吸 → 眉头内侧上抬 → 嘴角下沉、下巴起皱 → 明显时手捂嘴、下唇颤抖 | 当众时先压住（微弱），独处或事后再放开（明显） |
| 被当众表扬或起哄 | 尴尬、害羞，或骄傲 | 视线下移 → 压住笑 → 头侧转 → 再抬眼 / 骄傲：下巴抬起，小幅笑，挺胸 | 性格决定走哪一支；不要两支混用 |
| 被冒犯、挑衅 | 压抑怒意，可能爆发 | 原有笑意先退 → 眉间收拢、眼睑收紧 → 双唇压紧 → 爆发时头前探、张口 | 要保持克制就停在中等，并把残余写出来 |
| 发现被欺骗或背叛 | 困惑 → 确认 → 悲愤 | 视线在证据与对方之间来回 → 眉压低 → 确认后眉内侧上抬、嘴角下拉 → 含泪瞪视 | 转折要分段写，不要一帧切换 |
| 听到可疑的说法 | 怀疑、审视 | 停顿 → 眉微压、眼睑收紧 → 视线扫对方的脸 → 头微侧 | 多数用微弱到中等 |
| 巨响、突发危险 | 惊吓转为恐惧 | 头和视线转向声源（定向）→ 瞪眼、屏住呼吸 → 身体后撤 → 嘴角横拉 | 惊吓起得快；恐惧的残余要留长 |
| 看到或闻到恶心的东西 | 厌恶 | 视线落到对象上 → 皱鼻、上唇上提 → 头后撤、转开 | 礼貌场合压成微弱：只皱鼻翼一下，再抿唇 |
| 被拒绝、失恋 | 掩饰失望 | 笑容僵住 → 嘴角回落 → 视线移开 → 抿唇 → 勉强再笑 | 上半脸泄露，下半脸控制 |
| 告白或被告白 | 紧张转为惊喜或害羞 | 呼吸变浅、视线游移 → 听到关键句时眉毛一抬 → 压不住的笑 → 视线下移 | 双人场景要写倾听方的反应 |
| 离别 | 克制的悲伤 | 笑着说再见，下巴却在起皱 → 转身之后才让眉头和嘴角垮下来 | 对着对方时用微弱，背对对方时用明显 |
| 受伤 | 疼痛 | 瞬间眉压低、闭眼 → 吸气 → 手护住痛处 → 缓慢睁眼 | 看伤势轻重 |
| 等待结果 | 焦虑 | 视线在门和时钟之间游移 → 抿唇、吞咽 → 听到脚步声时身体一紧 | 以微弱持续为主，最后给一个明显的节点 |
| 获胜、成功 | 骄傲或狂喜 | 确认结果 → 小幅笑、下巴抬起 / 狂喜：张口喊、举臂 | 骄傲必须写身体 |
| 被揭穿、做错事 | 羞愧 | 视线落地 → 低头 → 肩膀内收 → 不看对方 | 不带笑，这是和尴尬的区别 |
| 看到壮观的景象 | 敬畏 | 慢慢抬头 → 眉抬起、嘴微张 → 屏住呼吸后缓缓呼出 → 身体静止 | 节奏放慢，峰值拉长 |
| 听到荒谬或轻视的话 | 不屑 | 一侧嘴角收紧上提 → 视线斜下 → 鼻腔轻哼 | 单侧动作；写明是哪一侧 |

## 混合与掩饰

- **组合**：复合情绪的原型大体是两个成分情绪的动作合集，口部动作互相冲突时只保留一个（Du 等 2014）。写法上，让上半脸（眉、眼）和下半脸（嘴角、唇、下巴）分别承载两种成分，例如“眉头内侧上抬的同时嘴角上扬”就是强颜欢笑或感动。
- **掩饰**（制片推导）：被控制的通常是下半脸，比如压唇、维持笑，而泄露的是眉眼和视线。写“笑容还在，但眉心一收、视线移开”，比写“假装没事”更可读。
- **转折**：旧表情先释放再起新表情，或者两者有一段可见的重叠，按故事意图选择。不要写成同一帧切换。

## 局部动作的生命周期

| 阶段 | 怎么写 | 常见误写 |
| --- | --- | --- |
| 基线 | 这个镜头开始时的可见状态，可以带轻微的旧表情 | 默认面无表情，或把“无动作”写成冻结 |
| 起始 | 变化第一次可见的时点或触发事件 | 把刺激出现的时间当成动作开始的时间 |
| 上升 | 幅度怎样变化，是否停顿、二次上升、与别的动作重叠 | 只给峰值，让模型自己补全过程 |
| 峰值 | 最大幅度，可以是一段略有变化的平台 | 峰值只有一帧，或匀速保持不变 |
| 释放 | 何时回落，回到基线还是被下一个动作接上 | 与起始镜像，或整张脸同一帧归零 |
| 残余 | 动作结束后仍可见的弱痕迹 | 为求“干净”把残余全部删掉 |

起落的快慢会改变观众的判断：同样的笑容，只改变起始、峰值、释放的时长，真实感评分就会变化。但不能反过来用“慢起就是真心”这类规则判断情绪真假。

## 并行而相互影响的轨

| 轨 | 写什么 | 与其他轨的关系 |
| --- | --- | --- |
| 面部局部动作 | 区域、侧别、起落、峰值、残余 | 可以错峰、重叠，不默认同步 |
| 注视 | 具体目标和转移时点，画外目标也要命名 | 眼和头共同实现目标，先后比例随任务而变 |
| 头部 | 转向、俯仰、点头及起止 | 与相机运动分开写 |
| 眨眼与眼睑 | 有功能的眨眼、眯眼、闭眼 | 可以作为倾听反馈，没有固定频率 |
| 声音与口型 | 台词、重音、停顿 | 发音和表情争用下半脸，口型优先 |
| 镜头与遮挡 | 景别、角度、遮挡时点 | 决定动作能否被看见 |

**景别可见性**：特写和近景能看到微弱的眉眼变化；中景只能读出中等以上的变化；全景和远景基本看不到面部细节，要改用头、肩、呼吸、手和身体姿态来表达，或者切一个近景。

## 相对时序

- 关键事件之间写 before、after、overlap、during、until，再在镜头里填大致秒段。例如：“先读完消息，短暂停顿，旧笑容退去后眉间收拢，话音结束才抿唇。”
- 多个动作同时存在时，写清是**重叠**还是**替代**。
- 停顿时要有可读的注视和姿态，不要把停顿写成所有通道冻结。
- 多峰、残余、左右不对称，只在有剧作理由时使用。

## 对白与倾听

- 对白逐字保留。说话时口型优先，表情主要放在眉、眼、脸颊，以及与发音相容的口角。唇部动作（抿唇、压唇、噘唇）放在词与词之间或说完之后。
- 写出**说前、说中、说后**：说前可以吸气、抬眼、准备；说中可在重音处加轻微点头或眉动，但不是每个重音都要；说后表情不要瞬间归零。
- 倾听者也在表演：写明他听到哪句时有反应（轻微皱眉、一次反馈性点头或眨眼），何时准备接话。倾听时皱眉不等于愤怒，也不要随机插入反馈。
- 写明“正在看谁、为什么移开视线”，不要照搬一种固定的眼神方向。

## 冲突处理

- **口型与下半脸表情**：要求“始终紧闭双唇”，但角色正在说台词时，改为“语音间隙短暂抿唇”，或者把冲突写出来交给创作者决定。
- **注视与头动**：把“看哪里”写成空间目标，眼和头是实现方式。近处的小目标主要用眼，大角度转向时带动头。
- **强度与景别**：要求“微弱”却用了全景，改用近景，或者换成身体动作来表达。
- **左右不对称**：只在角色设定、轻蔑类情绪或参考素材有依据时才写。
- **身份与相机**：表情变化时身份特征不变；头部转动与相机运动分开写。

## 示例：把情绪指令改写成过程

输入：“她听到好消息，先不敢相信，然后克制地笑。”（无对白，近景）

| 事件 | 大致时段 | 可见动作 | 其他轨 |
| --- | --- | --- | --- |
| 接收消息 | 开头 | 保持原有基线，不提前摆出笑脸 | 视线落在消息源上 |
| 定向与辨认 | 前中段 | 眉头内侧和上眼睑轻微抬起，随后减弱（惊讶，微弱） | 视线锁定新信息，头部不必跟随 |
| 停顿 | 中段 | 暂不出现笑容，眉眼留一点残余 | 注视明确，脸不冻结 |
| 克制笑意 | 末段 | 双侧嘴角小幅向外上方牵拉，闭口，末尾停住（愉快，微弱到中等） | 身份、口角方向、幅度保持稳定 |

## 面部失真清单

1. **突跳**：没有事件，眉、嘴角或眼睑却突然换了位置。
2. **机械匀速或镜像起落**：起始、峰值、释放是对称的线性坡，像两张图在形变。
3. **过度同步**：眉、眼、嘴、头在同一帧起落，没有先后和残余。
4. **强度超调**：本应克制的表情变成夸张的整脸动作，或者程度与景别不匹配。
5. **闪烁**：眉或嘴角高频抖动，或短暂消失后又出现。
6. **视线失靶**：眼神与目标不一致，或无缘由地反复扫视。
7. **眼头分离错误**：头转了但视线滑离目标，或头和眼机械地锁死在一起。
8. **眨眼错误**：随机眨眼打断关键词或关键注视。
9. **口型与表情抢通道**：说话时双唇紧压，笑容盖过口型，话说完口形还残留。
10. **身份漂移**：鼻、颌、牙齿、眼距随表情变成另一个人。
11. **头姿与相机混淆**：本应低头，却是整个画面平移。
12. **情绪定式化**：礼貌、紧张、真诚全都输出同一个满幅笑脸；每次“愤怒”都是咬牙瞪眼。
13. **事件与动作脱节**：消息还没看到，表情已经到达峰值；说话者还没停，听者已经反馈。
14. **伪自然化**：没有理由地随机眨眼、左右乱动、添加微笑。
15. **单帧正确、整段不通**：最好的一帧命中了目标，进入和退出却像瞬间换脸。
16. **对白前后断裂**：说话时正常，但说前没有准备，说后表情瞬间归零。

## 证据边界

以下每条只支持所列的最窄结论，不能外推为通用参数。

- **FACS 与版本**：FACS 描述的是可见的面部动作，不是情绪；2002 手册才是正式的评分版本。本文的区域词汇取自 CMU 公开的 1978 版词表，未按 2002 手册逐项核验。https://www.paulekman.com/facial-action-coding-system/ ；https://www.cs.cmu.edu/~face/facs.htm
- **FACS 考试说明**：强度分五级、按序数记录；说话时口部动作单独标记，不作为普通表情计分。https://www.paulekman.com/facs/facs-test/
- **Barrett 等 2019**：在自发情绪事件中，典型配置出现的平均比例约为 0.19（各类别 0.15–0.25）；面部配置既不稳定，也不具有特异性。https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/
- **Du、Tao 与 Martinez 2014**：230 人摆拍的 21 类表情原型动作及其出现比例；复合情绪的原型大体是两个成分的合集，冲突的动作只保留一个。表情是按提示摆出来的，不是自发表情。https://pmc.ncbi.nlm.nih.gov/articles/PMC3992629/
- **Matsumoto 与 Ekman（JACFEE）**：轻蔑刺激被编码为单侧的嘴角上提加嘴角收紧。https://davidmatsumoto.com/content/1997%20Matsumoto%20et%20al.pdf
- **Keltner 1995**：尴尬展示的序列为视线移开、压住笑、不带眼周的笑、头向下侧转；羞愧表现为头和视线向下、不带笑。样本来自美国。https://doi.org/10.1037/0022-3514.68.3.441
- **Tracy 与 Robins 2004、2007**：骄傲表现为小幅笑、头后仰、身体舒展、叉腰或举臂；只看脸时，识别率不高于随机。http://ubc-emotionlab.ca/wp-content/uploads/2011/12/psych-sci-2004.pdf
- **Prkachin 1992；Prkachin 与 Solomon 2008**：疼痛的核心动作是眉压低、眼周收紧、皱鼻或上唇上提、闭眼。https://pmc.ncbi.nlm.nih.gov/articles/PMC3296481/
- **Hess 等 1997；Wingenbach 等 2016**：强度越高，识别越准、越快。https://ursulakhess.com/resources/HBK97.pdf ；https://pmc.ncbi.nlm.nih.gov/articles/PMC4718603/
- **Ambadar、Cohn 与 Reed 2009**：同一类笑容可被读成愉快、礼貌或尴尬；眼周动作不能保证观众读出愉悦。https://pubmed.ncbi.nlm.nih.gov/19554208/
- **Krumhuber 与 Kappas 2005；Cohn 与 Schmidt 2004**：笑容的起落时长会改变真实感评分，但没有跨动作通用的时长。https://doi.org/10.1007/s10919-004-0887-x
- **Andrist 等 2012；Boker 等 2009**：眼与头的先后配比随任务而变；对话中的头动与表情有交互反馈作用。https://graphics.cs.wisc.edu/Papers/2012/APMG12a/APMG12a.pdf
- **Hömke 等 2018、2025**：倾听者的眨眼和眉间收拢可以作为反馈信号，没有固定频率。https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0208030
- **JALI 2016；Livingstone 等 2014**：口型要把唇和下颌分开处理；表情可以跨越说话的前后边界。https://www.dgp.toronto.edu/~elf/jali.html
- **Delis 等 2016；Scherer 等 2019**：面部动作的先后顺序会影响部分判断；情境参与表情的解读。https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.00508/full
