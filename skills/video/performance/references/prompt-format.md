# 输出格式

所有提示词都放在代码块里，方便复制。代码块外只写 `说明`（create 模式）或 `修改说明` 与 `保持不变`（edit 模式），不要重复提示词内容。

## create：单段

```text
【片段 1/1 · 约 X 秒 · 画幅】
人物：<名字或称呼>（<外观与身份锚点；用户提供了 @[图N] 就原样写上>）
场景与道具：<地点、光线>；<每个相关物体的位置与初始状态>
画面描述：
a–b秒：<景别与机位>。<外部事件>。<人物的可见反应：视线目标 → 头 → 面部局部动作的起落>；<身体、支撑、路径>；<手与物体的接触、物体状态>。
b–c秒：……
结束状态：<站位、各自手里拿着什么、物体状态、残余表情>
约束：<用户给的否定约束；对白保持原文；其他硬性要求>
```

写法要求：

- 第一行只写已知或已假设的值。用户没有给画幅就省略，时长写“约 X 秒”。
- 每个时间段先写镜头，再写事件，最后写人物。镜头运动和人物运动分开写。
- 情绪词只能跟在可见过程之后，作为补充解读，例如“……嘴角小幅上提并停住（克制的笑意）”。
- 对白写成 `<角色>：“原文”`，并放在说出它的那个时间段里；写出说前、说中、说后的表现。
- 时间段数量按事件而定，一般 2–5 段，不要为了凑满时长加入没有事件支撑的动作。

## create：多段

- 每一段都用上面的片段块，片段编号写成 `i/N`。
- 从第二段开始，`人物` 和 `场景与道具` 描述的初始状态必须与上一段的 `结束状态` 完全一致。前一段离座站着、右手拿着信，下一段开头也必须是站着、右手拿着信。
- 按事件边界切分，不要在一个动作中间切开。每段不超过 15 秒。

提示词之后写 `说明`，最多 5 条，只写两类内容：做了哪些假设（时长、画幅、补充的外观或道具），以及纯文字无法保证的项目（例如精确时点、细微的面部幅度）。

## edit

```text
<完整的新提示词。保留原有的分节标题、@[...] 引用写法、对白原文、时长与画幅、否定约束；只在这些之外改写表演、镜头和结构>
```

`修改说明`：逐条写“改了什么 → 为什么”，理由要指向具体的失真项或规则，例如“‘惊讶’改成先定向、再抬眉、后停顿（面部：情绪定式化 / 单帧正确整段不通）”。发现原提示词自相矛盾时，单独写一条“冲突：……；处理：……”。

`保持不变`：逐项确认保留清单，包括剧情事件的顺序、对白（逐字）、人名、素材引用、时长与画幅、分节、否定约束。某一项原提示词里没有，就写“无”。

## 示例：create

输入：“她听到好消息，先不敢相信，然后克制地笑。”

```text
【片段 1/1 · 约 6 秒】
人物：年轻女性，坐在书桌前
场景与道具：傍晚室内，暖色台灯；手机平放在桌面，屏幕朝上
画面描述：
0–1.5秒：胸像近景，固定机位。手机屏幕亮起并震动一下。她的视线从桌面移到手机屏幕，头部基本不动，面部保持原来的平静。
1.5–3秒：她读到消息，眉内侧和上眼睑轻微抬起，随后减弱；视线停在屏幕上，身体没有其他动作。
3–4秒：短暂停顿。她没有笑，眉眼留着一点抬起的痕迹，呼吸稍深，肩部随呼气轻微下沉。
4–6秒：双侧嘴角小幅向外上方牵拉，到中等幅度后停住，没有露齿；视线仍在屏幕上，最后轻轻抿了一下唇（克制的笑意）。
结束状态：坐姿不变，手机仍平放在桌上，脸上保留浅浅的笑意
约束：真人电影质感；不要字幕；不要夸张的整脸大笑
```

说明：
- 假设时长约 6 秒，场景与手机为补充设定，可替换。
- 纯文字无法保证嘴角恰好在第 4 秒开始上提；如需精确时点，要用参考视频驱动。

## 示例：edit

原提示词（用户要求：“她的反应太假了，优化一下”）：

```text
10秒，16:9。@[图1] 林夏站在门口，男友@[图2] 递给她一束花。林夏非常惊喜，开心地大笑，说：“你怎么来了？”然后很感动地抱住他。不要背景音乐。
```

输出：

```text
10秒，16:9。
人物：林夏 @[图1]；男友 @[图2]
场景与道具：公寓门口，门已打开；男友双手捧着一束花，花在他胸前
画面描述：
0–2秒：中景，林夏在门内侧，男友在门外。林夏的视线先落在男友脸上，停顿半拍后下移到花束，眉毛轻抬、嘴微张，身体没有动。
2–4秒：她的视线回到男友脸上，嘴角从微张转为上扬，笑意逐渐加深，露出一点牙齿；左手抬到胸前。说：“你怎么来了？”——说话时口型清楚，笑意保留在眼周和脸颊，话说完后笑容没有立即收回。
4–6秒：男友把花向前递到两人中间。林夏右手握住花束下部的包装，两人短暂同时拿着；男友先松手，花完全转到林夏右手。
6–10秒：林夏低头看了一眼花，再抬眼看他，眼眶微微发红，笑意转为嘴唇轻抿；她向前一步，左手绕过男友的肩抱住他，右手拿着花放在身侧。男友的双手环住她的背。镜头缓慢推近到两人的上半身。
结束状态：两人在门口相拥，花在林夏右手，门保持开着
约束：不要背景音乐；对白保持原文
```

修改说明：
- “非常惊喜，开心地大笑”改成：先认出人、再看到花、再笑起来，笑意逐步加深（面部：情绪定式化、事件与动作脱节）。
- 为递花补上接触顺序（握住 → 共同持有 → 男友松手），并写明花的最终位置（环境：接触缺口、物体状态跳变）。
- 冲突：原文“开心地大笑”与说台词同时发生；处理：说话时保留口型，笑意放在眼周和脸颊。
- 拥抱时林夏一只手拿着花，另一只手抱人，避免花凭空消失（肢体：手的冲突变体）。

保持不变：事件顺序（递花 → 说话 → 拥抱）；对白“你怎么来了？”逐字保留；人名“林夏”；@[图1]、@[图2] 的绑定关系；10 秒、16:9；“不要背景音乐”。原提示词没有分节。
